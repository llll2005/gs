## §1 3DGS-MCMC（Kheradmand et al., NeurIPS 2024）✅ 2026-07-28 核對

### 1.1 逐項核對結果：**實作全部正確**，含一個「不該修的 TODO」

| 項目 | 原文 | 我方實作 | 判定 |
|---|---|---|---|

| relocation 參數更新 | Eq.9 `μ_new=μ_old`、`o_new=1−(1−o_N)^(1/N)`、`Σ_new` 係數 | gsplat `compute_relocation`（CUDA `opacity_new=1-(1-o)^(1/N)`, `scale_new=coeff*scale_old`）+ host 同步更新 | ✅ 一致（2D scale 補零再截斷，係數只依 opacity 故維度無關）|

**→ 我方對 MCMC 的兩個公開斷言，現在是原文佐證而非只有原始碼佐證**：
1. **「MCMC 的 relocation 沒有任何 gradient gate」＝ 正確**（§3.4 只講 opacity multinomial）。
   ⚠ Gemini 曾稱「MCMC-GS 有位置梯度接受閥門」→ **確定是幻覺**，不可入報告。
2. **「MCMC 的 opacity L1 ＝ 我方框架的 `c_i≡1` 特例」＝ 正確**（Eq.10 的 `λ_o Σ|o_i|_1` 對每顆點等價計價）。

### 1.2 ★關鍵發現：L1 的真正角色是「relocation 的燃料泵」，不是壓縮

§3.5 標題就是 **"Encouraging fewer Gaussians"**，原文：
> "we encourage Gaussians to **disappear in non-useful locations and 'respawn' elsewhere**"

→ **opacity L1 的功能是製造死點供 relocation 回收**。拿掉 L1 ⇒ 沒有死點 ⇒ **relocation 實質關閉**
（實測 `reg000` churn ＝ **0.0%**，直接印證）。所以 `reg000` 不是「MCMC 少了一個正則」，
而是「**MCMC 的探索機制被靜默關掉**」，剩下 = 純建構式成長（+5%/事件到 cap）＋位置噪聲。

### 1.3 ★★為什麼拿掉反而更好：**depth-init 與 relocation 是替代品，不是互補品**

MCMC 的頭條賣點是**初始化不變性**。Table 1（同顆數）：

| | Random init | SfM init | 落差 |
|---|---|---|---|
| 3DGS (MipNeRF360) | 27.89 | 29.30 | **1.41** |
| **MCMC (MipNeRF360)** | 29.72 | 29.89 | **0.17** |

原文：§2「we tackle the source of the problem and **reduce the dependence on initialization itself**」、
§4.1「outperform 3DGS **regardless of the initialization strategy**」。

**我方已經用另一條路解掉初始化**：偽深度反投影 per-block（RTG-SLAM 式），點一開始就落在表面且 `α=0.99`。
→ **relocation 要修的東西我們已經先修好了**，於是它只剩成本：
- 每 150 步把 63% 的點搬家（0.40 it/s、+3G VRAM）
- host 按 opacity 抽樣 → 在「本來就都不錯的位置」之間洗牌 ＝ **等於注入噪聲**
- 而 §3.3 明說噪聲只該加在位置且要隨 opacity 衰減；relocation 卻是對 opacity/scale/color 全套重置

**這解釋了 +1.04 dB**：省下的不只是時間，是「不再破壞已經對的幾何」。

**可否證的預測（＝下一步實驗）**：把 init 換差（隨機／SfM 稀疏點），relocation 應該**由負轉正**。
若成立，我方的貢獻敘事就是「**在有良好幾何先驗時，MCMC 的探索機器是冗餘的；該把預算花在成本計價上**」。

### 1.4 因此的處置建議：**不拔除，改成條件化 + 變形**

| 選項 | 判斷 |
|---|---|
| ❌ 整套拔掉 | 不行。relocation 是我方**怪物回收**的唯一供給管道（`screen_size_prune_px` → dead mask → relocate）。拔掉後怪物只能硬剪（有損）|
| ❌ 保持現狀 | 不行。實測 −1.04 dB |
| ✅ **條件化**：`opacity_reg=0` 為新預設（**在 depth-init + cap 綁定的情境**），保留 conf 可開 | 已有數據支撐 |
| ✅ **變形＝DAR**：把均勻壓力換成**成本加權**壓力 → 只有「貴且無用」的點被推去死，好幾何不被騷擾 | 全長臂跑中 |
| ✅ 併用 Taming 式純建構式敘事 | 他們的 `Peak #G ≈ Final #G` 論證與 `reg000` 同向，可互引 |

### 1.5 尚未採用但可用的概念（來自本篇）

- **Eq.8 的 opacity-gated 噪聲** `ε_μ = λ_lr·σ(−k(t−o))·Σ·η`（`k=100, t=0.005`）：噪聲隨 opacity 上升而關閉。
  我方 `noise_lr` 已用同式（繼承），但**這個 sigmoid gate 的形式可以借去做 DAR 的反向**：
  對 opacity 高的點降低成本壓力（目前 DAR 對真表面 `ĉ=2.47` 反而收較多，靠 Adam 回推硬扛）。→ 📐 候選設計。
- **Fig.3「Limited budget」**：MCMC 宣稱**預算越緊、對 3DGS 的優勢越大**。我方正在緊預算 regime 卻得到反向結果
  → 這個矛盾本身是論文可寫的觀察點（差異＝初始化品質）。
- Appendix A 有 Eq.9 的完整推導（保持 `P(g_new)≈P(g_old)`）——若要論證我方 relocation 變形的合理性可引。

### 2.2 ★★我方 −0.46 dB 的原因：**原文從未把 SB 用在 Gaussian kernel 上**
Table 3 的每一列 SB 都同時開著 **Beta Kernel + Kernel-Agnostic MCMC**：
```
3DGS+MCMC sh3          24.29     ← 基線
DBS(Beta kernel)+MCMC sh3  24.45  ← +0.16 = Beta Kernel 的貢獻
+Kernel-Agnostic MCMC sh3  24.57  ← +0.12 = 他們的 MCMC 變形
+sb=2                      24.79  ← +0.22 = SB color 的貢獻(在前兩者之上)
```
**沒有任何一列是「Gaussian kernel + SB color」＝我方組態。** 所以「SB 勝 SH3」這個結論**沒有在我方組態下被證明過**，
我方實測 −0.46 dB 不是矛盾，是**在原文未涵蓋的組合上的新數據點**。

**三個候選解釋，前兩個原文直接支持**：
1. **原文 Limitations 明寫**：「the **frustum model causes Beta Kernels to optimize flat geometries for distant
   backgrounds**, which impacts the overall beta geometry distribution」→ **空拍城市全是 distant background**。
2. **Fig.6 顯示 SB 的勝場在 specular 分解**（長椅高光/盆栽容器）。**100m 空拍幾乎無視角相關高光** →
   SB 的 lobe 沒東西可模，而 SH1-2 的寬低頻能吃跨視角漸變（曝光/大氣）。**＝我方「頻譜洞」診斷的原文佐證。**
3. `sb_params_lr` 未調（原文預設，我方沿用）。

→ **報告寫法**：不要寫「SB 比 SH3 差」，要寫「**SB 的增益依賴 Beta Kernel 與 specular 內容；在 Gaussian kernel
＋漫射空拍場景上，其 2.4× 的 F 槓桿以 −0.46 dB 為代價**」。這是有原文根據的差異化觀察，不是失敗。

### 2.3 沒移植但可用的：`(1−o)^100` 噪聲閘（Eq.9）
DBS 把 MCMC 的 sigmoid 噪聲閘換成 Beta Kernel：`ε = λ_lr·B(o_i;b′)·Σ_η η`，`b′=ln 25` ⇒ `β=4e^{ln25}=100`
⇒ 噪聲尺度 ＝ **`(1−o)^100`**（原文：「to resemble the fall-off behavior of the original logit function」）。
比 MCMC 的 `σ(−k(t−o))` 解析上更簡潔（`o=0.005→0.61`、`o=0.05→0.006`、`o≥0.1→~0`）。

**⚠ 用在 DAR 上要小心（我方判斷）**：形式上很誘人——把 stride 乘 `(1−o)^p` 就能保護真表面（`o>0.7`）
而不放過霧/塵埃/怪物（實測 `o` 分別 0.01–0.1 / <0.01 / 0.028）。**但它不可由我方拉格朗日導出**：
`Σ c_i·o_i` 對 `o_i` 的偏導就是 `c_i`（常數），沒有 `(1−o)` 因子。強行加＝把 opacity 當價值訊號偷回來，
**正是我方批評 MCMC 的那件事**。
→ **原則性的修法是把惰性的 `u` 換成多視角 `T·α` 貢獻**（我方 §5 已標為理論上對稱的版本，程式也在）；
`(1−o)^p` 只當**廉價 stopgap** 且必須標為啟發式。📐 兩者都待實驗。

### 2.4 我方未採用且確認不需要的配套
- **Beta Kernel 幾何**：SB color 在數學上獨立於幾何 kernel（`B(·)` 只是同一個函數形式用在視角方向上），
  故「只移植色彩」在結構上成立。⚠ 但 §2.2 說明**效能上未必獨立**。
- **Kernel-Agnostic MCMC**：他們把 MCMC 的 relocation 推廣到任意 kernel。我方用 2DGS（Gaussian 族）
  ＋MCMC 原版 relocation → **不需要這個推廣**。

## §3 LightGaussian（Fan et al., NeurIPS 2024）✅ 2026-07-28 核對 —— **找到一個真缺漏，已修**

### 3.1 原文公式
```
Eq.3  GS_j = Σ_{i=1}^{MHW} 1(G(X_j), r_i) · σ_j · T · γ(Σ_j)       T = Π_{i<j}(1−σ_i)
Eq.4  γ(Σ) = (V_norm)^β ,   V_norm = min( V(Σ) / V_max90 , 1 ) ,   V(Σ) = (4/3)π·abc
```
`σ_j·T` **就是 α-blending 權重**，所以 Eq.3 ＝「跨所有視角所有像素累積的 α·T」×「正規化體積^β」。

### 3.2 逐項核對
| 項目 | 原文 | 我方 | 判定 |
|---|---|---|---|
| 貢獻項 `σ_j·T` | 跨 MHW 累積 `α·T` | trim rasterizer 的 `record_transmittance` 累積 `T·α` | ✅ **忠實**（同一乘積，且由 CUDA 內精確算出，非近似）|
| 體積 → 面積 | `V=(4/3)π abc`（3 軸）| `prod(get_scales())`（2 軸面積）| ✅ **必要的正確改寫**——surfel 第 3 軸恆為 0，照原式算每顆都是 0 |
| **`min(·,1)` 截斷** | Eq.4，原文理由：「volume alone tends to **overemphasize background Gaussians**…**avoid excessive floating Gaussians**」| **原本缺失** → 2026-07-28 補上 | ❌→✅ **這是真缺漏，見 §3.3** |
| 除以 `V_max90` | Eq.4 | 原本缺失，一併補上 | ⚠ **但它不改排序**（全體常數），見 §3.3 |
| `β` / `v_pow` | 「β provides additional flexibility」，未給值 | `v_pow=0.1`（沿用其開源預設）| ✅ 合理 |
| 跨視角聚合方式 | Eq.3 是**跨所有視角求和** | **top-K(=5) 各視角貢獻的平均** | ⚠ **有意偏差**：原式獎勵「被很多視角看到」；分塊城市場景中「只被少數視角看到」是常態（塊的視角覆蓋有限），求和會冤枉合法的稀見幾何。且 top-K 與 CityGSV2 trim 的自帶機制一致。**要在論文寫明是偏差** |
| Gaussian Co-adaptation | 剪完 fine-tune 5000 步「without additional densification」| 我方在 30k 剪、之後照常訓練 | ✅ 同精神（且我方後續訓練更長）|
| Distillation / VQ | §3.3 SH 蒸餾、§3.4 VQ | **未採用**（我方 F 槓桿走 SB color；VQ 有 `tools/vectree_lightning.py` 另線）| ✅ 非必須配套（獨立模組）|

### 3.3 ★缺漏的影響：只缺了「有影響的那一半」
- **除以 `V_max90`**：對所有點是**同一個常數**，`(V/V_max90)^β = V^β / V_max90^β` → **不改排序**，缺了無害。
- **`min(·,1)` 截斷**：**會改排序**。它讓面積前 10% 的高斯全部拿 `γ=1`，**不再因為更大而得到額外重要度**。
  缺了它 ⇒ 一顆面積 1000× 中位數的浮游物拿到 `area^0.1 = 10^0.3 ≈ 2×` 加成
  ⇒ **貢獻只有真表面一半的浮游物仍排在前面** ⇒ 剪錯人。
  **這正是我方的怪物/浮游物病理，而原文引入此截斷的動機一字不差就是它。**
- **對既有數據的影響**：帳面最佳 `24.47`（aggr17 + LightGaussian 20% prune@30k）是在**缺截斷**的版本下拿到的。
  結果仍好，說明缺漏沒有毀掉機制（`v_pow=0.1` 把 1000× 壓成 2×，影響溫和）；
  但修後應該**多剪大浮游物、少剪細幾何** → 值得重測一次同組態確認是否再進步。🧪 排入待辦。

### 3.4 沒採用但可用的概念
- **`V_norm` 的 p90 正規化思路 ＝ 我方 `ĉ` 用中位數正規化的同一手法**（不同論文、同一工程直覺）→ 可互引，
  說明「資源量必須先正規化再進判別式」不是我方臨時發明。
- **Eq.5–6 的偽視角蒸餾**（`t_pseudo = t_train + N(0,σ²)` 在訓練視角附近取樣合成新視角監督）：
  對我方 **held-out 泛化**與「塵埃是視距相關」的擔憂是現成工具——可用來測 `cull_dust` 在 novel view 上是否仍無損。📐 候選。

### 4.1 ★我方 stretch 項＝可證的上界，不是「物理直覺」
`Σ' = J W Σ Wᵗ Jᵗ`（3DGS §4，承 EWA 的局部仿射近似），
`J = [[fx/z, 0, −fx·x/z²], [0, fy/z, −fy·y/z²]]`。對 `Σ=s²I`、`fx=fy=f`，記 `a=x/z, b=y/z, r²=a²+b²`：
```
J Jᵗ = (f²/z²)·M ,   M = [[1+a², ab],[ab, 1+b²]]
tr(M) = 2+r² ,  det(M) = (1+a²)(1+b²) − a²b² = 1+r²
tr² − 4det = (2+r²)² − 4(1+r²) = r⁴   ⇒   √ = r²
λ_max = 1+r²  ,   λ_min = 1
```
⇒ **`stretch = √λ_max = sqrt(1 + (x/z)² + (y/z)²)` ＝ 我方公式，逐字相符**（各向同性下**精確**，
各向異性下為上界，因 `r = 3·f·s_max/z·stretch` 取 `s_max`）。
且 **`λ_min = 1` ⇒ 拉伸純沿徑向**（朝/離畫面中心），次軸完全不變 → 解釋了「離軸近點被拉成掃過畫面的長條」。
→ **`現行方案與公式.md` §2.3 可從「物理項不是魔術常數」升級為「投影 Jacobian 最大特徵值的平方根」。**

### 4.2 ★★近相機怪物是 3DGS 自己命名的病理，而 MCMC 把它的解藥刪了
3DGS §5.2 原文：
> "our optimization can get stuck with **floaters close to the input cameras**; …An effective way to moderate
> the increase in the number of Gaussians is to **set the α value close to zero every N = 3000 iterations**."
> "we periodically remove Gaussians that are **very large in world-space** and those that have **a big footprint in viewspace**."

**⇒ 3DGS 原版有三道防線**：(a) 每 3000 步 opacity 歸零重置、(b) world-space 尺寸剪、(c) **viewspace footprint 剪**。
**MCMC 把 ADC 全部當 heuristic 移除 → 三道全失**。我方 `screen_size_prune_px` 重新引入的正是 **(c)**
→ **我方 docstring「MCMC has no counterpart of vanilla ADC's max_screen_size prune」現在有原文佐證** ✅

**論文敘事價值（強）**：我方的怪物問題不是新病理，是**3DGS 明文記載、原本有解藥、被 MCMC 刪掉**的病理。
我方貢獻＝「用成本計價把 (c) 從啟發式門檻升級為預算對偶」。
- 🧪 **尚未重新引入 (a) 每 3000 步 opacity 重置**：它專打近相機浮游物。但那是**巨型 churn 事件**，
  與我方 churn 淨負的發現衝突 → 列為候選但**預期為負**，優先序低。
- 🧪 (b) world-space 尺寸剪：我方 scale L1 已在做軟版本。

### 4.3 ⚠ 我方峰值模型的 `B·N` 項，物理身分未被原文支持（只有實測擬合）
3DGS §6 明說 backward **不存** per-pixel blend list，而是**重走 per-tile 排序陣列**
（"we instead choose to traverse the per-tile lists again; we can reuse the sorted array of Gaussians and
tile ranges from the forward pass"），每像素只存最終累積 α。
⇒ 依原文，backward 的記憶體應該 **∝ 相交數**（排序陣列）**＋ ∝ 像素數**（常數），**沒有明顯的 ∝N 項**。
但我方標定出 `B ≈ 1550 B/pt` 且 K=1→2.63G / K=4→1.14G 實測吻合。
→ **`B·N` 是經驗擬合項，物理身分不明**（候選：trim rasterizer 的 per-Gaussian 中間緩衝——2D 協方差/conic/
colors_precomp/radii/depth keys）。
**★這正是 b12@2M 模型低估的頭號候選**：若 `B·N` 其實有一部分**不可被 K 分攤**（例如 O(N) 的投影緩衝，
每條帶都要投影全部 N 個點），則高 N 時模型把它算進可分攤項 ⇒ **低估固定成本 ⇒ 低估峰值 ⇒ OOM**。
**廉價驗法**：固定 load、在高 N（1.7–2M）掃 K，擬合 `peak = fixed + splittable/K`；
若 `fixed` 明顯大於 `model_state + A·N`，差值就是被錯放的不可分攤項。🧪 排入待辦。

## §5 AdamW（Loshchilov & Hutter, ICLR 2019）✅ 2026-07-28 —— **反而簡化了我方立論**

### 5.1 原文形式：解耦項是**純的** `λθ`，**沒有** `1/√v̂`
Algorithm 2 第 12 行：
```
θ_t ← θ_{t−1} − η_t ( α·m̂_t/(√v̂_t + ε) + λ·θ_{t−1} )
```
（`given α=0.001, β₁=0.9, β₂=0.999, ε=1e-8` → **我方 `dar_eps=1e-8` 與 Adam 正典一致** ✅
⚠ 但 Adam 正典是 `√v̂ + ε`（ε 在**外**）；我方 DAR 用 `√(v̂+ε)`（ε 在**內**）以取得 `1/√ε=1e4` 的上界，
這是**刻意的偏差**，已在程式註解說明。）

### 5.2 ★原文替我方兩個實測結果提供了官方解釋
> "with L2 regularization both types of gradients are **normalized by their typical (summed) magnitudes**,
> and therefore weights x with large typical gradient magnitude s are regularized by a **smaller relative
> amount** than other weights. In contrast, **decoupled weight decay regularizes all weights with the same
> rate λ**, effectively regularizing weights x with large s **more** than standard L2 regularization."

1. **「`opacity_reg` 調了沒用」有了官方解釋**：L1 在 loss 裡會被 Adam 的 `√v` 正規化 →
   梯度≈0 的塵埃點，正則梯度相對地被放大到主導（每步位移≈lr，與係數無關）＝我方實測（0.007→0.002 幾乎無變化）。
2. **AdamW-GS 把 `1/√v̂` 加回解耦項，違背 AdamW 的核心論證**（AdamW 解耦的目的正是**移除**這個正規化，
   讓「所有權重同一個 rate λ」）。

### 5.3 ★★因此我方形式其實是 AdamW 正典的自然推廣（比原本的敘事更強）
實測 `u = √ε/√(v̂+ε) ≈ 1` 對 99% 的點成立 ⇒ 我方 stride 實際上就是
```
o_logit_i −= lr_o · min( λ · ĉ_i , C_t )
```
＝ **AdamW 的解耦衰減，但把「所有權重同一個 rate λ」推廣成「rate λ·ĉ_i 依資源成本加權」**。
這正是 AdamW 論證所支持的方向（解耦項不該被 `√v` 正規化）。

→ **報告寫法升級**：不要寫成「我們沿用 AdamW-GS 但預條件沒作用（尷尬的免責聲明）」，
要寫成「**我方回到 AdamW 正典的解耦形式，並以資源成本 `ĉ_i` 取代其均一 rate；AdamW-GS 的 `1/√v̂`
預條件是更強的推廣，在本工作的 regime 中實測為惰性（`u≈1`），故保留但不宣稱其貢獻**」。
程式保留 `u`（零成本，且在 `v̂ ≳ ε` 的 regime 會自動生效）。

### 9.1 ★交叉驗證：我方 `harvest_dust_trim` 的 trade-off 與文獻一致

### 9.2 價值訊號：`I_i = Σ_j w_ij`，`w = T·α·G^2D` ＝ **第四篇用 blending weight**
（LightGaussian／Taming／Diet／**Mini-Splatting**；FastGS 是唯一的例外且批評它。）

### 9.3 ★★Blur Split 的 `S_i` ＝ 螢幕足跡的第五種語意，而且對我方最有用
```
Eq.2   G^blur = {G_i | S_i > θ_blur·H·W} ,  θ_blur = 2e-4
       S_i = Σ_x δ( i(x) = i_max(x) )        i_max(x) = argmax_i w_i(x)
原文：「The value of S_i **can be computed during the forward pass of rasterization**」
```
`S_i` ＝ **我在多少像素上是「最大貢獻者」＝我實際擁有的畫面面積**（不是我覆蓋的面積）。
他們用它抓 under-reconstruction（`S` 大＝一顆糊一片＝該分裂）。

**★對我方的價值（這是本輪最有用的發現）**：`S_i` 與「原始足跡 `c_i`」的差正好切開我方兩個病理——
| 點型 | 覆蓋足跡 `c_i` | 擁有面積 `S_i` | `S_i/c_i` |
|---|---|---|---|
| **霧**（binning 82%）| 大 | ≈0（被前面的擋住，從不是最大貢獻者）| **≈0 → 殺** ✓ |
| **近相機怪物**（o=0.028）| 爆大 | ≈0（低 opacity，T·α 小）| **≈0 → 殺** ✓ |
| 次像素塵埃 | ≈1 tile | ≈0 | ≈0 → 殺 ✓ |
| **真表面** | 中等 | 幾乎等於足跡 | **≈1 → 保護** ✓ |

⇒ **`v_i/c_i = S_i/c_i` ＝「我把多少光柵化成本轉換成實際擁有的像素」＝真正的產出率（yield）**，
兩端都 render-grounded、都能在 forward pass 算出。**這是比我方現行 `1/√v̂` 好得多的效用訊號。**
- **歸屬**：`S_i` 的定義與計算是 Mini-Splatting 的（他們當 split 準則）；**拿它當 `v/c` 比值的分子是我方用法**。
- **實作**：需要 rasterizer 逐像素追 argmax（小幅 CUDA 改動）。
  **廉價近似（免 CUDA）**：我方現有 `record_transmittance` 給 `Σ(T·α)`，用 `Σ(T·α)/c_i` 當代理
  ——**這正是我方原本設計的 v/c**，故 Mini-Splatting 同時**驗證了我方 v/c 的設計方向**並給出更銳利的變體。

### 9.4 第三篇指出「共位/重疊」問題
「**overlapping** phenomenon, where most Gaussians are **clustered in certain areas** but sparse in neighboring parts」
→ 繼 Diet §3.2、我方 relocation 觀察之後，**第三篇獨立指出同一個病理**。

## §10 Confident Splatting ✅ + §11 StopThePop ✅✅ 2026-07-28

### §10 Confident Splatting（Gemini 轉述大致正確，但漏了一個理論點）
- 每 splat 兩個可學參數 `(α_i, β_i)`，信心度 `c_i = E[Beta] = α_i/(α_i+β_i)`（Eq.1-3）。
- **`σ^effective = σ(σ_i^original) · c_i`** ——信心度**乘進 opacity** 進入渲染路徑。
- 三個正則（Eq.4）：**sparsity `L_sparse=(1/N)Σc_i`（＝又一個 `c_i≡1` 的 L1，我方表格無誤）**、
  **negative entropy**（罰低熵＝阻止過早自信）、saliency ranking。
- 賣點＝**一次訓練得到整條品質/大小曲線**（測試時選門檻），對照 RadSplat 每個門檻要重訓。
- **★對我方的理論價值**：他們把「**表面有多不透明**」與「**這顆該不該存在**」拆成兩個變數。
  **我方（承 MCMC）用同一個 `o_i` 兼任兩職**——這正是 DAR 壓真表面（`ĉ=2.47`）會傷畫質的根因：
  為了預算壓 `o` 的同時也把表面變透明了。⚠ 但補一個專用存在變數 ＝ +2 floats/pt（25→27, +8%），
  與我方 F 槓桿衝突 → **記為理論觀察，不採用**。廉價替代＝事後用 `Σ(T·α)` 排序也能得到那條曲線。

### §11 StopThePop ✅✅ —— **推翻我方當日的「推翻」，找到今天最大的槓桿**
**⚠ 我方 2026-07-28 稍早寫「任何收緊框的做法都救不了 b12」——這句話太寬，必須修正。**
分清楚兩件事：
- **框「形狀」收緊**（正方→矩形 AABB）＝ 實測只 **1.14×**（先前的推翻對這件事成立）
- **按「貢獻」剔 tile**（StopThePop §3.4）＝ **完全不同的機制**，且正好打在我方病理上

原文確認我方程式診斷：
> "we start with an **axis-aligned bounding rectangle using the largest eigenvalue** of the 2D covariance matrix…
> **This conservative estimate gives very large bounds for highly anisotropic Gaussians**"
> §3.4 Tile-based culling：對每 tile 求 `x̂ = argmax_{x∈X} G₂(x)`（Eq.5），若 `G₂(x̂) < ε_O = 1/255` 則剔除該 tile。
> **Fig.6：每 tile 的平均高斯數減少 ~44%。**

**★我方推導出更簡單的閉式版本（不需 per-tile argmax）**：
```
剔除條件  o·exp(−½d²) < 1/255   ⟺   d > sqrt( 2·ln(255·o) )   ＝ 精確支撐半徑
且        o ≤ 1/255 = 0.0039     ⇒   全域都到不了門檻 → 整顆可從 binning 剔除
現行 TIGHTBBOX: truncated_R = sqrt(9 + ln o)     ← 啟發式（原註解自承 "no use in the paper"）
```

|---|---|---|

| 0.02 | 1.81 | 2.26 |

**★★無損性已驗證**：`forward.cu:408` 與 `backward.cu:322` **都已經有 `if (alpha < 1.0f/255.0f) continue;`**
⇒ 最大 alpha < 1/255 的 tile 對**前向與反向都貢獻零** ⇒ 在 binning 階段剔掉它 **位元級相同**。

**★★基準修正（2026-07-28 當日）**：`auxiliary.h` 是 **`#define TIGHTBBOX 0`** ——TIGHTBBOX **是關閉的**，
實際出貨行為是 **所有點一律 3-sigma 正方框**（與 opacity 無關）。我方先前把 TIGHTBBOX 當現行行為＝錯，
