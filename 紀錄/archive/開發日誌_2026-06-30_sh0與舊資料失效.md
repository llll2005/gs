# 開發日誌 2026-06-30 — sh0 發現、sh0 run 負結果、舊資料/舊 coarse 失效

## 1. 核心發現：28.9 是純 sh0，不是 sh2
- 查 `outputs/citygsv2_mc_aerial_sh0_trim/blocks/block_7/checkpoints/epoch=107-step=24000.ckpt`（3,975,909 顆）：
  - `_active_sh_degree=0`、`shs_rest` 形狀 **(N, 0, 3)**（零個高階 SH）、只有 `shs_dc`。
  - 該 config 雖寫 `sh_degree: 2`，但 `overwrite_config` 載 sh0 coarse 後保持 sh0。
- 記憶體：每顆 sh0=13 / sh2=37 / sh3=58 floats（含 Adam ×3：sh0≈156B、sh2≈444B）。
  - 6GB 能塞：sh0→~4M（=28.9）；sh2→~1.4M。**sh2 4M 必 OOM**（之前 epoch131 densify 期 5.16GB 爆）。
- 結論：aerial 俯視漫反射 + 單一固定光照 → 不需 view-dependence；**sh0 被硬體鎖死且剛好最優**。
- 動作：四個 fine-tune config `citygs_ft60k_coarse{3x,2x,1.2x,4M}.yaml` 全改 sh0；coarse configs 本就 sh0。

## 2. sh0 run 的負結果（重要）
跑 `citygs_ft60k_coarse3x`（sh0，60000 步，完整跑完沒 OOM）：

| step | N |
|---|---|
| 14999 | 1.47M |
| 29999 | **4.96M**（15k→30k 暴衝） |
| 60000 | 4.96M |

- **val/psnr = 24.16**（SSIM 0.666 / LPIPS 0.454）。eval 設定與 28.9 完全相同（split reconstruction / step / ratio 0.01 / ds 1.2）。
- **4.96M > 28.9 的 3.97M，PSNR 卻只有 24.16 ≈ 我們舊的 MCMC 1.5M(24.30)** → 3× 顆數零增益 → **顆數不是王道，這 4.96M 是垃圾球/floater**。

### 診斷：28.9 真實 recipe vs 我們的差異
| 參數 | 28.9（成功） | citygs_ft60k_coarse3x（24.16） |
|---|---|---|
| coarse(init) | 4.39M, ds 1.2（全解析度） | 1.21M, ds 3（低解析度） |
| densify_until | 12000 | 30000 |
| opacity_reset | 2100 | 6000 |
| max_steps | 24000 | 60000 |
| grad_threshold | 0.0002 | 0.0002 |
- 低解析度 coarse 欠擬合→梯度高→densify 暴衝；+ densify 太久 + 剪枝太少 → 一堆 floater。
- **錯不在 sh0，在 coarse 解析度 + densify/prune 排程。**

## 4. 本 session 的 pipeline 工具改動（程式碼層，已驗證）
- `max_split_size_mb:128`：碎片化 OOM 解（torch 2.0.1 用不了 expandable_segments）。對結果零影響。
- **`partition_subdir`**：新參數，partition 寫到 `partition/<subdir>/partitions-dim_..._...`，避免不同 coarse 的 partition 互相覆蓋。改了 `utils/partition_citygs.py`（argparse + 讀 config + 組路徑 + 改用 `search_load_file` 吃目錄）和 `internal/dataparsers/colmap_block_dataparser.py`（欄位 + 組路徑）。
- partition 為必經步驟，讀 fine-tune config 的 `initialize_from` 做 projection 指派 → 換 coarse 必重跑（`doc/run&eval.md`）。
- 深度圖已 resize：`estimated_depths_2/`(960×540)、`estimated_depths_3/`(640×360) 對齊 ds2/ds3 相機解析度。
- partition 改用 matplotlib `Agg` backend → 只存 `partitions.png`、不彈窗。
- `save_iterations` 確認會存「可續跑 .ckpt」（`trainer.save_checkpoint`，含 optimizer）。
