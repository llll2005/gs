# SF-MCMC 實驗計畫 2026-07-04 — G2 查證、實作、smoke、相鄰塊(quad)實驗

> 使用者指示（2026-07-04）：「查證後作 smoke 驗證，那之後作相鄰塊實驗」。
> 演算法設計背景見 `紀錄/方向重定調_2026-07-03.md` §6。

## 1. G2 novelty 查證（通過）
- **SteepGS（CVPR 2025, arXiv 2505.05587）**：split 判準 = splitting matrix
  S = E[dL/dsigma * Hess_theta(sigma)] 的 lambda_min < 0；子點恰 2 顆、沿 ±v_min 放置；
  **opacity 對半（w=1/2）**；嵌在 grad-densify ADC 迴圈、非 MCMC、無預算、無 dead 回收。
- **AdpSplit（2026, arXiv 2605.06876）**：L1 像素誤差區域統計驅動 split、子點數自適應；
  取代 vanilla binary split、目標是加速；標準單場景、非 MCMC、無 dead-funding。
- **判定**：兩篇皆 grad-densify 家族的 split 運算元改良。**「MCMC 骨幹 + dead-funded
  預算制 split + 2D surfel + city-scale 6GB」未被佔。** 可借：SteepGS ±v_min 放置
  （v2 升級項）；他們 opacity 對半會毀 alpha=0.99 opaque 先驗 → 反證我們用 MCMC
  重整化（1-(1-o)^(1/2)，0.99→0.9）是對的。

## 2. ★ 新機制洞見（讀 base MCMC 源碼，比「缺 split」更硬的論文故事）
base MCMC 的成長算子對高 opacity 父點是**動力學簡併**的：
1. 新點/復活點寫在父點**完全相同位置**（`_get_new_params` 直接複製 means）；
2. 探索 noise 被 `op_sigmoid(1-o, k=100, x0=0.995)` 門控 → **只有 opacity ≲ 0.005 的
   點拿得到 noise**，高 opacity 雙胞胎拿到的 noise ≈ 0；
3. `replace_tensors_to_optimizers` 把兩者 Adam 動量都歸零 → 參數相同 + 梯度相同 +
   動量相同 → **雙胞胎只能靠浮點非決定性極慢分離**。
→ MCMC 把回收預算堆成冗餘疊層（Z-fighting stacks，呼應 Gemini 的 Normal-Consistency
觀察），而非新的空間結構。這解釋 gg-MCMC 換權重 net-zero（不管把複製體派去哪，
它都黏在父點上）。**SF-MCMC 的對稱破缺 split（±offset + 主軸收縮）直接修這個簡併。**

## 3. 實作（2026-07-04 完成）

## §6 quad merge 結果（2026-07-08）：D4 首次量化 = 獨立訓練塊拼接 −7dB
- **quad 終值**：b7 24.30/0.755/0.309、b8 23.62/0.705/0.430、b12 22.45/0.594/0.740
  （偏差:screenprune+cap1.0M）、b13 23.87/0.690/0.474（偏差:screenprune）。
  per-block 平均 23.56。
- **merge（官方工具,enlarge=0）**：各塊裁到自己 cell 串接 = **1,184,719 顆**
  （b7 339k/b8 262k/b12 172k/b13 412k）——**每塊模型只有 11-27% 點在自己 cell 內**，
  其餘為跨界脈絡點、全數被裁 = 掉分物理來源。`outputs/quad_merge_aggr17/`。
- **naive 全圖 val**：12.80/14.87/14.75/14.78（掉 8-11.5dB）——被「子集孤島效應」
  污染（val 相機看 ±8 單位、quad 只覆蓋 5.7×4.9），**不可當 merge 掉分引用**。
- **公平量測（新工具 `tools/eval_quad_merge_footprint.py`）**：篩「視錐足跡全在
  quad 內」的 val 相機（14 個,b12×8/b13×5,b7/b8 為 0——它們 val 相機全看出界），
  merged 15.87 vs single 22.88 = **覆蓋視角仍掉 7.0dB**（最慘 2753.png：33.8→17.9）。
- **機制（視覺取證,GT/single/merged 三聯圖）**：不是破洞而是**跨塊擁有權不相容**——
  (a) 近界內容的擁有塊只從遠處/斜角看過它,其 in-cell 版本近看=尖刺垃圾;
  (b) 鄰塊 cell 內的邊緣殘渣漂在本塊乾淨幾何前面。兩者都源自**獨立訓練
  （depth-init 各自起家,無共享骨架）**——ADMM 時代量到的「boundary 匹配對一致」
  不矛盾:那是同 init 的匹配對;拼接災難來自未匹配的周邊體積與品質衰減梯度。
- **結論**：per-block 贏（24.3 vs 官方式 21.78-24.16）**不可裸加成全域**;
  官方 coarse-init 的真正價值=跨塊一致性錨,單塊品質反而其次
  （我們量過 aggr17-COARSE 單塊只 22.27）。**depth-init（單塊強/拼接弱）vs
  coarse-init（單塊弱/拼接穩）的張力 = D4 研究空間**,也是效率前緣故事必須面對的洞。
- **候選下一步**（quad 資產可直接復用）：
  (1) **post-merge consolidation finetune**（merged.ckpt + 四塊聯集相機,~5-10k 步
