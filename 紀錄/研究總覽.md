## §1 命題：成本感知的密度控制

```
max Q(theta_S)   s.t.   (1/K) * sum_{i in S} c_i <= B(hardware)
  c_i = 螢幕足跡（精確量＝光柵器的 tiles_touched；訓練期用覆蓋像素，排序相關 0.84~0.99）   lambda = 影子價格
```
- **兌現的位置＝剪枝端**：trim 判準 V/C（各視角總貢獻 ÷ 覆蓋像素）＋ opacity 二元熵 => best1：同品質、精確 Load −1/3（`實驗分析/13`）。
  背包的對偶 `V − lambda·C > 0 ⟺ V/C > lambda`。
- **c_i 主要是時間成本**：同 N 下 Load 大降時 VRAM 只降約 6%；常駐 864~928 B/顆只看 N（`02`）=> VRAM 的槓桿是 N、SH 階數、塊外顆粒（`17`）。
- 取樣端（增生乘成本項）、約束端（成本預算取代 cap）、軟投影（GaussianSpa 式）、定價自決容量 v1 都沒贏 => 已關閉。
- 文獻歸屬：RAIN-GS（全域螢幕預算）與 Taming 3DGS（densify 分數含覆蓋像素、符號為正）是「先前方法都是 c≡1」的反例；
  倖存的區別是 **c 當價格**（綁在預算上、用在剪枝）vs c 當偵測器。各機制出處 => `機制出處.md`；理論推導 => `理論_ADMM統一框架.md`。

**沒做的構想（延後／不做＋理由）**
- 固定厚度（使用者 11-03）訓練版：**延後**——渲染端 10 cm 透空 −10% 但空拍 11～16% 像素被改、前方遮擋不降；先要有把地面蓋滿的機制（`37`）。
- 把面元合併成單一大高斯（使用者 11-03）：**沒做**——合併只併同平面鄰居、不移動高度，融大會丟紋理；地面已在正確高度、顏色均勻的區域要再減顆數時再做。
- tile 改非同步：**不做**——整塊同步損失上限 8.9%（`28` §6）。2DGS 梯度的代數化簡：**延後**——只省算術、累加量個數不變，估 backward 幾個百分點；重開＝backward 再成為唯一瓶頸（`28` §8）。
  半精度梯度：**不做**——3090 非 tensor 半精度與 FP32 同速、累加會掉精度；重開＝換到半精度有倍速的卡。
- 單目深度的三種用法都**不做**（硬性貼齊、SfM 局部校正、多視角融合給高樓）——11-11 改用 SfM 三角形校正（每張影像自己的 SfM 點，可靠區誤差 0.05%），取代了這些用法（`37`）。用模型自己的深度當閘門：**不做**——會循環（`32`）。
- 整個關掉 trim、只靠合併：**不做**——trim 也剪合併處理不了的（灰塵、浮塊、內部零貢獻），是主要的減顆數來源；關 trim 時 FusedAdam 有未修的 contiguous 錯誤；改做的「合併優先 trim」已測沒作用（`過程/23` §3、`25` §1）。
- 鄰塊背景／共識背景取代盒外高斯：**不做**（使用者 10-17）——先跑的塊分數低、Load 上升、輪流訓練的載入時間太長；改走塊外遮罩（`理論_ADMM統一框架.md` §10）。
