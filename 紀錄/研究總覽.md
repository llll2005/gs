## §1 命題：成本感知的密度控制

```
max Q(theta_S)   s.t.   (1/K) * sum_{i in S} c_i <= B(hardware)
  c_i = 螢幕足跡（精確量＝光柵器的 tiles_touched；訓練期用覆蓋像素，排序相關 0.84~0.99）   lambda = 影子價格
```
- **兌現的位置＝剪枝端**：trim 判準 V/C（各視角總貢獻 ÷ 覆蓋像素）＋ opacity 二元熵 => best1：同品質、精確 Load −1/3（`實驗分析/13`）。
  背包的對偶 `V − lambda·C > 0 ⟺ V/C > lambda`。
- **c_i 主要是時間成本**：同 N 下 Load 大降時 VRAM 只降約 6%；常駐 864~928 B/顆只看 N（`02`）=> VRAM 的槓桿是 N、SH 階數、塊外顆粒（`17`）。
- 取樣端（增生乘成本項）、約束端（成本預算取代 cap）、軟投影（GaussianSpa 式）都沒贏 => 已關閉。
- 文獻歸屬：RAIN-GS（全域螢幕預算）與 Taming 3DGS（densify 分數含覆蓋像素、符號為正）是「先前方法都是 c≡1」的反例；
  倖存的區別是 **c 當價格**（綁在預算上、用在剪枝）vs c 當偵測器。各機制出處 => `機制出處.md`；理論推導 => `理論_ADMM統一框架.md`。
