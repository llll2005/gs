## 鐵律
只用當前資料／姿態輸入與 CityGS 相同（sparse/0＝GT 姿態 x1/100）／繁體中文＋ASCII 數學／指令用腳本或單行／
大實驗前先用 CPU 或短跑驗前提／拿檔案當基準前先查來源／排程只用 `scripts/runner.sh`＋`queue.txt`／
新機制必印「首次觸發」，「沒效果」的結論要先出示它觸發過／交 ckpt 前先自檢渲染／不准用場景單位的距離門檻。
