## 結論
- **步數與 SH 都是「本塊新視角 PSNR 越短／越低越好」**，但**代價在 PSNR 量不到的地方**：LPIPS 變差、幾何 F1 單調下降、馬路靠地底面元（`18`）。
  使用者 10-18 目視 15k＋SH1 的 test 圖：細節不足、有 floater、馬路糊 => **15k 不當基底**（`../new_archived/已關閉的線.md` B）。
- SH1 兩塊都是 PSNR 最好（+0.53／+0.23），模型 37%、峰值 2.09 GB；但 F1 0.537／0.681、馬路地底比例比 SH3 高 => SH1 也不當預設（同檔 C）。
- 同塊對官方：15k＋SH1 換進官方模型 +0.53／+0.54 dB（扣光柵器落差約 +0.2）、時間 4%、VRAM 25%、盒內顆數 66%；**幾何輸**。
- 現行方向：SH3＋dist100＋塊外遮罩，cap × 步數全因子消融（`研究總覽` §0、§6）。

- 時間與步數幾乎成正比（約 1 分／千步）；累加式 trim 在短步數下省 9~17%。

- 解讀（推測，未直接驗證）：GT 有逐幀曝光不一致（`研究總覽` §3.4），高階 SH 把它背進「隨視角的顏色」—— 訓練視角對、新視角錯。
- SH 越低每視角 Load 越高（顏色表達力少，用面積補）。
- 換塊評測工具 10-17 修正：低 SH 候選要補 0 到基準的 SH 長度（`eval_mode` 載入時合併成 `shs` 鍵；原本只處理 `shs_rest` => 兩次 assert 失敗）。

## 限制
- 只有 b6、b12；每臂單次。
- 15k 的 test 圖使用者目視不合格（細節、floater、馬路）—— 換塊 PSNR 沒有反映；之後定案要同時看 LPIPS、F1、`18` 的馬路診斷與 test 圖。
