## 結論

- **現行（10-14）best1 = best0 ＋ opacity 二元熵正則 ＋ trim 判準 V/C**：本塊幾何區域 b6 −0.09／b12 +0.01 dB，精確 Load **−34%／−35%**；
  兩個機制各自省的 Load 幾乎直接相加（二元熵 −12／−23%、V/C −17／−10%），合開沒有崩潰。
- best0（opacity_reg 0.002 → 0）本身是「同品質、較便宜」：舊配方 full44 比 best0 的 Load 高約 50%（b6 +50%／b12 +54%），品質 −0.05／+0.09。
- **全場景對官方**：我方 4x4（full44 舊配方）27.74／LPIPS .129、N 17.6M、合併模型 Load 中位 2.52M；官方 release 27.26／.154、論文設定 27.28／.147，Load 都 5.92M
  => **渲染成本 −57%、品質同級或略好**（release 合理分數 27.2~27.6，`09` §0.1）。best1 全場景未訓練（單塊 Load 再低約 1/3）。
- 「減少成本」最好的手段是改配方，不是調低 cap：同 Load 下只調 cap 的曲線一律在配方改動的點下方（5x5 實測，舊版 05 §0.3）。
- ⚠ c_i 主要是時間成本：同 N 下 Load 大降時 VRAM 只降約 6%（`02`）。
