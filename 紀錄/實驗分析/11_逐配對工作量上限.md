## 結論

- **現行（10-03）**：`tile_cull`（①）實測配對 -35.7%（b6 60k、6 視角），與這裡量的上限 34.4% 相符，渲染逐位元相同；
  但逐 tile 判斷本身讓 forward +30%、增生期每步淨 +2.9%（比只開 record_reduce）=> 現行實作不採用（`10` §6）。`record_reduce` 已採用。
- **為什麼配對少了 36%，forward 反而變慢 30%（10-10 使用者問）**：被剔除的配對本來就**很便宜** —— 像素迴圈遇到 alpha<1/255 只做一次相交與指數就跳過，
  不做混合、不寫記憶體；而要判定「整個 tile 沒有任何像素過門檻」，必須對每個配對把 tile 內 256 個像素的 alpha 都算一次，
  等於額外跑一遍 forward 的前半段＋一次重新排列（compact）。⇒ **省下的是便宜的工作，付出的是一次完整掃描**；要賺回來，判定必須比渲染便宜得多
  （例如用保守的幾何測試先剔除，或在 trim 的 record pass 順便記下、跨多步重用），這就是待辦的「配對貢獻 bit／覆蓋遮罩」。
- **① 30~42% 的 binning 配對整個 tile 都沒有 alpha≥1/255 的像素** => StopThePop 式的逐 tile 精確剔除可以去掉它們，渲染逐位元不變（`tile_cull` 已實作並實測：配對 -35.7% 但 forward +30%，現行實作不採用，`10` §6）。
- **② 20~40% 的配對在 tile 已經全部飽和後才輪到**：forward 已會整塊跳過，backward 仍逐輪載入 => Taming §4.1 的 last-contributor 略過可以省。
- 每個像素的迴圈只有 **17~22.5%** 真的有混合，其餘是 alpha<1/255 或幾何不相交。
- **③ 低誤差的 tile 並不比較便宜**：工作量比例 ≈ tile 比例（60k 時 L1<0.02 的 tile 佔 61~62%、工作量也 62%）；15k 時只有 25~33%。
- **④「驗過不再驗」後期大致成立但要隨機重驗**：門檻 0.02 時 30k→60k 仍低 94~95%、變差 1.5 倍以上 4.7~4.8%；15k→30k 變差 9~10%。
  => 誤差引導抽樣的可省上限受「何時開始」限制；優先序在 tile_cull 與 record_reduce 之後。

工具自檢：逐 tile 加總的配對數 ＝ 光柵器 binning 總數（b6 30k：272,177,802 ＝ 272,177,802）。

**tile_cull 的實作要點**（`rasterizer_impl.cu` 的 `tileMayContribute`，保守上界，只會多留不會多剔）：
- rho2d 下界：像素中心矩形到投影中心的最近距離；
- rho3d 下界：像素 → splat UV 是單應 `p = Tu x Tv - y (Tu x Tw) - x (Tw x Tv)`（xy 項因 `Tw x Tw = 0` 消失）=> 矩形的像是凸四邊形，原點在內取 0、否則取到四邊的最近距離；四角 p.z 不同號就不剔。
- 只用在非 record 的呼叫：record（trim）在 alpha 判斷**之前**就累積 => 剔除會改變 trim 判準。
- 新 kernel，不碰 preprocessCUDA（那裡多一行程式碼就會擾動基準路徑的 codegen）。⚠ `tiles` 輸出會變成剔除後的數。

|---|---|---|

15k → 30k（門檻 0.02）：b6 仍低 88.0%／變差 9.4%、b13 86.8%／10.2%。

**想法的瑕疵（使用者的「完美 tile 不再算」，2026-10-02 討論）**：
1. 完美像素的梯度正是讓它保持完美的力量；顆粒跨 tile、跨視角共用 => 不算完美 tile 後可能被不完美那邊拉壞，而且沒有力量拉回 => 必須重驗。
2. 凍結的顆粒仍要渲染（遮擋、貢獻其他像素）；能省的單位是 (視角, tile)；Adam 對零梯度仍照動量更新、MCMC 噪音與正則照常 => 要配 selective Adam。
3. 省多少看工作量比例，不是 tile 比例（本表：兩者相近）。
4. 判準要絕對門檻；只在訓練視角上完美（val⊂train）。
**改良版**：好 tile 每步只隨機算比例 p、loss 乘 1/p（梯度期望值不變、持續重驗）。

## 限制
- 60 個訓練視角、單一模型（cs60_conic）；誤差是訓練視角上的（val⊂train 性質）。
- 工作量用「每像素實際跑的迴圈次數」近似 forward 與 backward。
