## §4 固定厚度（使用者 11-03「讓面元有厚度、厚度固定、不需要控制」；渲染端，不重訓）
面元沿法向加固定厚度 s_w，沿射線取 3D 高斯（面內 s_u、s_v、法向 s_w）的最大響應：
```
q_min = |s|^2 - (s . d_uv)^2 / |d|^2,   d = (u0 - Cu, v0 - Cv, -Cw),   Cw = -(n . p) / s_w
（(u0, v0) = 2DGS 的平面交點；(Cu, Cv, Cw) = 相機在面元正規化座標的位置，可由 transMats 反解；s_w -> 0 退回 2DGS、正對面元不變）
```
驗證：單顆 70° 斜面元，CUDA alpha 對 Python 數值解（沿射線二次式頂點）中位誤差 4e-8（厚度 0／2／5／20 mm 都一樣；最大 9.5e-3 在厚度 0 也有＝原本 3σ 截斷）。
