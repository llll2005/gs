## 結論
- **起因（10-29 使用者用 viewer 看 A＋dist4 全場景）**：① 海面浮起、低角度時遮住低樓；② 立面「毛邊」（10-05 舊最佳沒有）；③ 高樓頂樓整個糊掉；④ 全場景在本機 viewer 卡。
  1M 版也一樣。**MatrixCity test 741 幀全是空拍高度 => test PSNR 對這幾項都是盲的**（我們用 PSNR 一路選配方，所以沒被擋下）。
- **海面浮塊是 opacity 設定造成的，二分到 10-10**（§1）：b12 海上浮塊 舊最佳 1.1k、CityGS 1.7k → best0（拿掉 opacity L1）22k（×20）→ ＋二元熵＋V/C 100k（再 ×4.5）→ 現行 A＋dist4 129k。
  b0 的 opacity 變體裡只有「L1 0.002＋熵關」（oe）壓到 8.5k，但它每塊 [solo] 訓練 +49%（`20` §6）。
- **立面毛邊＝面元朝向亂＋小面元多**（§2）：b3 朝向一致度 現行 0.765（亂向 37%）vs 舊最佳 0.802（30%）、CityGS 0.928（12%）；現行 o>0.5 的面元是舊最佳的 4.6 倍、長軸只有一半。
  ❌ 我先提的「毛邊＝不透明度二值化」被使用者目視推翻（b2 oe 的 o>0.99 只有 6%，看起來和 86% 的 ed10b4 一樣）。
- **法向正則修得了朝向、修不了浮塊**：b12 渲染式法向一致性（λ 0.0125）0.80 → 0.95（勝 CityGS 0.908）、F1 0.727 → 0.739；但浮塊只少 9%（105k → 95k）——
  法向一致性對「沿法向平移」不變，浮塊變成整齊的水平片（40%）而不是消失。且法向＋深度 60k 每塊 +63% 時間（`18`）。
- **頂樓糊掉是新視角問題，三個模型都有**（§3）：高樓區在 MatrixCity test 視角 b3 24.54 vs CityGS 24.92、b2 23.61 vs 23.63；使用者目視舊最佳與 CityGS 也在高處糊掉 => 資料只有空拍斜拍。
- **馬路地底面元又退步**（§4）：10-22 遮罩＋dist100 曾壓到 b6 8.5%／b12 31.4%（低於 CityGS 16.3／38.5），ed10b4 21.3／46.2、A＋dist4 24.5／55.2。
- **深度補點初始化**（Tier B 改用單目深度點）b0 浮塊 64k → 24k（−62%），但換塊與 F1 都沒變（`21` §6）；**撒點讓浮塊加倍**（50k → 102k）。
- **海面的外部資訊**：單目深度在海面不準（b12 無 SfM 格只有 26% 落在地面 ±0.05、26.5% 高於 0.1；b0 44%／21%）＝和浮塊高度 0.1～0.5 同量級 => 不能逐像素用；單目深度 loss 臂也沒減浮塊。
- **10-29 實作：幾何閘門**（`internal/metrics/geom_gate.py`，`1ef5e82`，預設全關，8 個 CPU 測試通過）＝使用者「把法向正則弄到透明度熵的算法裡、只取要的參數、減少計算」（§5）。

- 86% 在無 SfM 的格，俯視圖沿海岸線分布（全場景 52.2 萬顆、1.88%）。成因判讀：水面沒有 SfM 點、反光無紋理，空拍角度下浮在水上的暗色顆粒與水面同色 => 光度 loss 分不出；

## §5 幾何閘門（10-29 實作，`1ef5e82`，預設全關）
```
共面一致（逐顆、不渲染）：近鄰＝Morton 序兩種軸序前後各 k/2 顆（近似 kNN，O(N log N)）
  w_ij = o_j * exp(-(d_ij . n_i)^2 / (sig*s_i)^2 - |d_ij|^2 / (rad*s_i)^2)
  q_i  = sum_j w_ij |n_i . n_j| / sum_j w_ij                 1＝和鄰居共面
  L_plane = lam_p * mean_{i in 抽樣} o_i * sum_j w_ij (1 - |n_i . n_j|) / sum_j w_ij      （用 |cos|：cos^2 在 90 度梯度為 0）
多視角深度支撐：r_ik = (z_ik - D_k) / D_k，視窗內累積；mean r < -0.05（一直在單目表面前方）或 min |r| > 0.05（從未貼面）=> 不支撐
閘門 g_i = (q_i >= tau 或 q 無效) 且 有支撐
用法：熵的「往 1 推」只給 g_i=1；g_i=0 改加 -log(1-o)（對 logit 的梯度＝o，飽和也推得動）；MCMC 增生／搬遷抽樣乘 g
```
已排的 E 臂（b3、b12；家族 `g44s30km25fssh16di4<tag>_`，對照 A＋dist4）：
| 臂 | 改了什麼 | 想回答 |
|---|---|---|
| nm2／nm4 | 渲染式法向一致性 0.0125，每 2／4 步算一次 | 法向正則的時間能不能壓到可接受（每步算 +63%） |
| pl | 逐顆共面正則 0.01＋共面閘門 tau 0.5＋MCMC 抽樣乘閘門 | 不渲染的共面能不能取代法向 loss，並讓亂向的不透明面元被回收 |
| l1e | 0～15k L1 0.002＋熵只往 0 推，15k 起關 L1、熵雙向 ×4 | 前期 L1 能否把浮塊壓回舊最佳、又保住熵的速度 |
| pll1e | pl＋l1e | 兩者是否互補（毛邊＋浮塊） |
| ds | 多視角深度支撐閘門＋MCMC 抽樣乘閘門 | 一直浮在單目表面前方的顆粒能否被收掉 |
