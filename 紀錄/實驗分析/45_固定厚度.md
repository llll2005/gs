# 45 固定厚度（訓練版，11-29）

> 使用者 11-03 的構想：「讓面元有厚度、厚度固定、不需要控制」。
> 11-29：「低角度露縫直接做，報告完專題就結束了，沒有結束再做這種選項」。
> 重開條件（`new_archived/已關閉的線.md` G）已成立：最終版低角度透空 5.5%／5.7%（b1／b4），11-03 是 5.84%。
> 也就是「把地面蓋滿」的機制做完之後，低角度露縫幾乎沒變（`42` §2c）。

## 1. 做法（commit dc74b2c）
- **厚度用相對尺度**：s_w = 比例 x min(s_u, s_v)，不用場景公尺（遵守不用場景單位門檻的規則）。
  - 11-03 渲染端測的是絕對厚度 2／10／50 cm；那一版沒進訓練。
- **渲染**：每個像素的射線，對「面內 s_u、s_v，法向 s_w」的 3D 高斯取沿射線的最小 Mahalanobis 距離。
  - C = 相機在面元正規化座標的位置 (Cu, Cv, Cw)；s = 射線與面元平面的交點。
  - 用 Lagrange 恆等式寫成閉式，分子分母都是平方和，沒有大數相減：

    ```
    rho' = [Cw^2 |s|^2 + (Cu s.y − Cv s.x)^2] / [(s.x − Cu)^2 + (s.y − Cv)^2 + Cw^2]
    ```

  - 厚度 0（Cw → inf）或正對面元時，rho' 退回 |s|^2；斜看時 rho' 變小，面元沿視線方向變寬。
  - 深度照舊用平面交點（深度上限、dist 正則的語意不變）。
- **梯度**：
  - 光柵器回傳 dL/ds（取代原本 |s|^2 的 2s）與 dL/dC。
  - C 由 renderer 用 PyTorch 算：Cu = t_u·(c−μ)/s_u、Cv = t_v·(c−μ)/s_v、Cw = n·(c−μ)/s_w。
    梯度經 autograd 回到位置、旋轉、尺度。
- **所有路徑都改了**：
  - forward：一般與 V/C 累加兩個迴圈、trim record（record_reduce）。
  - backward：完整路徑（幾何步）、lean 路徑（`renderCUDA_opt` 新模板參數 THK，多 3 個歸約槽）。
  - binning 盒、精確盒（`skip_box`）都外擴「中心沿法向 ±R·s_w 投到螢幕的位移」。
  - 幾何配對遮罩（`exact_strip_cull`）對有厚度的顆粒不跳。
  - `tile_cull` 不支援（現行配方沒開；開了會報錯）。
- **評測**：換塊評測與低角度工具把候選塊的厚度轉成逐顆 property `thick`（候選塊 = 比例、最終版其他塊 = 0）。
  厚度 0 時逐位元同原寫法。
- **臂元件**：`thk<k>`（比例 = k/100；`--model.renderer.init_args.surf_thick_ratio`）。

## 2. 正確性（本機，`tools/probe/check_surf_thick_1129.py`）
- **單顆合成面元的 alpha 對數值解**（沿射線求 3D Mahalanobis 最小值）：法向與視線夾角 30°～89.5°、比例 0.3／1.0，
  差的中位數 3～6e-6，最大 4.5e-5（float 精度）。
- **厚度 0（逐顆 thick 全 0）對不開**：lean 與完整路徑的渲染都逐位元相同。
- **單顆有限差分對 autograd**（loss 只放在 alpha > 0.05 的像素，避開 1/255 截斷）：
  - 位置、log 尺度、旋轉的相對差 1e-4～8e-3，和不開厚度的對照同級；lean 與完整路徑都是。
  - 多顆真模型的有限差分連對照都只有 1～12%（截斷與排序的跳動），只能當參考。
- 比例 0.3 時，空拍 test 視角有 12.8% 的像素改動超過 1/255（11-03 渲染端 10 cm 是 11～16%）=> 必須訓練時就開，不能只在渲染端加。
