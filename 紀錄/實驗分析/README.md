## 共同約定
- **命名（使用者 10-29）**：圖與新文字不用「官方」——CityGS 就寫 CityGS（release／論文設定）、MatrixCity 就寫 MatrixCity（test 741 幀）。
- **年代**：全部是 2026-09-13（影像↔姿態修正）之後的資料。
- **評量**：換塊評測（本塊幾何區域 PSNR，雜訊 ±0.03；b0 重跑差 0.11）、區塊 F1、MatrixCity test 741 幀（全場景）；單塊 val／held-out 大半是塊外，只做同塊相對比較（`../研究總覽.md` §6）。
- 成本欄若沒有特別標，都是**精確 Load 中位**（光柵器實際 binning 的 (tile, 顆) 對數，每視角取中位）。
- **每個跑次的圖表資料包**：每個訓練跑完自動呼叫 `scripts/lab/post_run_data.sh`，量測存到 `outputs/<跑次>/blocks/block_<塊>/chart_data/`；
  彙整用 `python tools/chart_data_summary.py [--filter 跑次]` => 不用為了畫圖重跑。
- 新結果：寫進所屬那條線的文件（表＋`tools/plot_analysis.py` 的數字）並重畫；若改變了前緣，再更新 30；新的線加一份 `NN_…md` 並在腳本 `DOCS` 加同名項。
