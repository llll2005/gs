## 1. SH 的可觀測維度
### 1.1 推導
顏色 c(d) = Σ_k s_k Y_k(d)（16 個基底 x 3 色），訓練只在「看得到這顆的相機方向」上約束它。對每顆累加
M_i = Σ_視角 w_iv Y(d_iv) Y(d_iv)^T（16x16），則在訓練視角上的加權顏色能量 = s^T M_i s；M_i 的零空間＝訓練完全看不到的 SH 組合。
全域：M̄ = mean_i M_i / tr(M_i)。

### 1.2 只用相機幾何就算得出來（b2，1009 台相機、盒內 10 萬顆樣本、每顆中位被 173 台看到；`tools/probe/sh_observability_1121.py` 的 CPU 版）
- M̄ 特徵值（%）：36.4、26.3、20.8、6.89、5.74、2.34、0.549、0.535、0.228、0.19 ｜ 0.009、0.0069、0.0044、0.00012、0.0001、7e-7
- 逐顆有效維度（特徵值 > 1e-3 x 最大）：中位 10、p10 9、p90 10。
- 按渲染貢獻加權（record pass 的 Σ T·α、21 台相機）算出的特徵值形狀幾乎相同 => **訓練前只靠相機幾何就能定出基底**（零成本）。
- 看不到的 6 個方向全是「同一個 m、不同 l」的組合：Y22＋Y32、Y2-2＋Y3-2、Y20＋Y00＋Y30、Y11＋Y21＋Y31、Y1-1＋Y2-1＋Y3-1、**Y10（∝ z）＋Y00（常數）**。
- 理論：空拍視角的仰角落在一個窄帶 => 帶內只跟仰角有關的函數 ≈ 常數＋一次項（2 維）=> 每個方位階 m 最多 2 維可觀測：
  m=0：4 -> 2、|m|=1：各 3 -> 2、|m|=2：各 2 -> 1、|m|=3：各 1 -> 1，合計 **10**，與量測一致。
- 附帶解釋：3 階係數能量（平均 3.5%）比 1 階（0.56%）大——看不到的方向沒有約束、係數自由漂移（§2 的統計）。

### 1.4 保留 DC 的投影（關鍵修正）

## 3. 四元數長度
規範自由度：R(q) = R(λq)，渲染只看方向；但 Adam 在 q 空間走固定步長 => 旋轉角的步長 ∝ 1/|q| => |q| = 0.58 的顆粒轉得比 |q| = 1.89 的快約 3 倍。
這是「參數裡完全沒用的一維悄悄改了學習率」；改成每步正規化會改變訓練動態，要訓練才能判斷 => 只記錄。

### 1.6 真正的低維參數化（11-22 使用者「實作，然後分別排 4x4」；臂 `shb<k>`，renderer `sh_basis_k`，bece12c）
- 高階 SH 只存 K＝k−1 個基底係數 a（每色版），rest = U a；U＝該塊訓練相機幾何的高階 Schur 子空間（同 §1.4，保留 DC）。第一次訓練步把 shs_rest [N,15,3] 換成 [N,K,3]。
- 光柵器（`set_sh_basis(U)`）：forward 在前處理把 a 展開成 15 個係數再算顏色；backward 照原式算 15 個係數的梯度後乘 U^T 縮回 K 維；
  backward 內的 SH Adam 與每 16 步累加直接在 K 維上做 => 參數、Adam 兩份、梯度都只有 K 維，沒有任何 N x 45 的暫存；基底模式一律走分開存放，也省掉每步的 SH 串接。
- 存 ckpt 時還原成 15 維（合併、評估、viewer 不用改）；⚠ 這種 ckpt 的 Adam 狀態是 K 維，不能直接接續訓練。
- 本機驗證（b2、k=10、lean 與完整路徑）：影像逐位元相同；dL/da 與 U^T dL/drest 相對差 7e-8～7e-6（atomic 雜訊級）。基底關閉時既有 kernel 機器碼逐條相同。
  backward 內 Adam 的基底分支要 FusedAdam，本機沒測，lab 第一塊會驗證（log `[sh-basis] ✅`）。
- 預期：k=10 每顆 SH 48 -> 30 個 float（總參數 58 -> 40，−31%；k=8 -> 34，−41%），常駐記憶體同比例下降；時間：Adam 與記憶體流量少、前處理多一次 15 x K 展開 => 預期持平或略快，以全場景實測為準。
