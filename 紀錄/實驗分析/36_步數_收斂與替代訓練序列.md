## 現況與結論
- **60k 對 30k 多買到的是幾何與表面完整，不是畫質**：held-out PSNR 平（11.660 vs 11.663）、塊內 test PSNR 平（20.56 vs 20.61），
  但 F1 0.387 vs 0.362、地面覆蓋 0.75 vs 0.55 層、低角度透空／破洞 0.8／0.7% vs 2.7／2.3%，時間 2 倍。和 lab b6／b12 的步數表（`30` §2）同一個形狀。
  => 使用者看到的「30k 比 60k 差」對得上的是低角度破洞與地面覆蓋，held-out 量不到。
- **B 後段低解析度（30k 後再用 1/2 解析度跑 15k）**：幾何拿到 60k 增益的一半多（F1 0.377），但塊內 test PSNR −0.23、時間 +24% => 不採用。
- **C 前段低解析度（< 7.5k 1/2、< 15k 3/4）**：快 15%，但幾何全面變差（F1 0.322、地面覆蓋 0.31、破洞 5.9%）=> 失敗；原因是**點精靈**（下一點）。
- **D 位置學習率 x2**：F1 0.376（60k 增益的 54%）、地面 0.65、低角度破洞 0.8%（≈ 60k）、held-out 平、時間 +6%（N 也 +6%）、立面比例 23.0 → 17.6%。
  最便宜的一半增益。⚠ MCMC 噪音 ∝ 位置 lr，所以 D 同時把梯度步長和噪音都 x2 => 拆因已排（Dg 只有步長、Dn 只有噪音）。
- **★ D 的增益來自梯度步長、不是 MCMC 噪音**（11-07 拆因）：只有步長 x2（noise_lr 減半）F1 0.371、地面 0.65、破洞 0.7%、點精靈 18.7% ≈ D；
  只有噪音 x2 跟底一樣（F1 0.359、點精靈 26.2%）。=> 30k 的幾何差在「位置走得不夠快、面元還沒張開就縮成點精靈」。
- **★ 60k 的曲線（§2）**：F1、held-out、地面覆蓋、低角度破洞在 40k 就到 60k 終點的 90% 以上（F1 0.382／0.387、破洞 0.9／0.7%）；40k → 60k 幾乎不再變。
- **★ 點精靈下限 30k（`35` §5）**：F1 0.376、地面覆蓋 0.77（＞ 60k 0.75）、破洞 1.2%、held-out 平、LPIPS .7667、+9% 時間（v2 修中）。
  和 lr x2 各拿到一半多的幾何增益 => **兩個疊起來已排**（能不能 30k 追上 60k、時間只多一點）。
- **點精靈（11-07 新發現，`35` §5）**：不透明顆粒裡「長軸 < 1 cm、靠 2DGS 低通濾波畫成約 1 px 的點」的比例，跟上面的幾何排序一致：
  60k 16.0% < D 18.8% < 30k 26.3% < C 67.9%（塊內；CityGS 0.0%）。60k 跑次裡 30k 時只有 13.5%，增生結束後逐步升到 17.3% => 增生停了就沒人回收。
  => 60k 的優勢有一部分是「比較少顆粒掉進點精靈」；點精靈下限 `px_floor` 已排（b3 30k）。
