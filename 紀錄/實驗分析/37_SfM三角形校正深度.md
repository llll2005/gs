## §1 只補前面（規格 3 §4-3，`capfc`；使用者 11-13「只補前面作」）
- 實作（5164465）：光柵器 backward 的 `g_cap_grad_mode_b`（`set_depth_cap_grad_mode`；只在 backward、只在有上限圖的完整路徑）。
  模式 3：後面的貢獻（z·icap > 1）不拿 B 的 α 梯度、也不拿 dB/dz；前面的（z·icap <= 1）照舊只有經由 α 的那一項（−accum·dL_dB）。forward、loss、其他通道的梯度都不變。
  metric `depth_cap_grad_mode`（`internal/metrics/mcmc_citygsv2_metrics.py`）、renderer 帶進 raster settings、元件 `capfc`（要和 tricap 一起用）。
- 檢查（`tools/check_depth_cap.py`，本機與 lab 都過）：重編前存基準、重編後 `cmp`：模式 0 渲染與 10 個通道逐位元相同、梯度只差 atomic 順序（1e-9）；`fc`：

| 檢查 | 結果 |
|---|---|
| 模式 3 的渲染／10 個通道 vs 模式 0 | 逐位元相同 |
| 全在上限前面的 192 顆：梯度 vs 模式 0 | 最大差 2e-5（重跑雜訊 2e-4） |
| 全在上限後面的 2,153 顆：全部參數的梯度 | 恰為 0（模式 0 是 3.8～10.6） |
| 不含 B 的 loss：梯度 vs 模式 0 | 差 4.9e-9（重跑雜訊 3.7e-9） |
| 用完回到模式 0 | B 的梯度與最初的模式 0 相同 |
| 全在前面、梯度非 0 的顆粒：dL/d不透明度 < 0 | 100%（都往更不透明推） |
- **已排（lab，新底上，b1／b4；評估標籤 `capfc`）**：`+capfc`（權重 0.5）、`tricap2g+capfc`（權重 2、只在增生期）、對照 `tricap2g`。
- 判讀（規格 3 §3.3）：`+capfc` 對新底畫質不掉、地下再降 => 採用候選；`tricap2g+capfc` 比 `tricap2g` 少掉分 => 「只補前面」讓上限可以加重（原本權重 2 掉 −0.15／−0.10 dB、地下 −73／−72%）。
