## 0. 一頁摘要

**一句話**：4x4 分塊 × 每塊 17k 步的 2DGS＋MCMC。用 SfM 三角形校正的單目深度當幾何先驗（塊外遮罩、深度上限、起點），
海面當成一個多視角共識的平面物件，光柵器與排程做了一連串不改畫質的加速；16 塊各留盒內顆粒合併成全場景。

| 全場景（741 幀） | PSNR ↑ | SSIM ↑ | LPIPS ↓ | 訓練 ↓ | 顆數 | FPS ↑ | 訓練峰值 VRAM |
|---|---|---|---|---|---|---|---|
| **我方 新底 9（平均 1M／塊）** | **27.750** | .8631 | .1599 | **1.23 h**（16 塊純訓練；整個訓練任務 1.44 h） | 約 10.7M | **67.8** | **2.66 GB** |
| **我方 新底 9＋平均 1.5M／塊** | **27.940** | **.8721** | **.1425** | 1.49 h（整個訓練任務 1.65 h） | 16.01M | （待：獨佔重量） | 3.90 GB |
| CityGS（release，同一支工具；論文自報 27.23／.857／.169） | 27.261 | **.8671** | **.1540** | 約 69.4 h（coarse 3.4 h＋16 塊細修 66.0 h） | 24.48M | 21.9 | 12～21 GB／塊 |

- **優勢**：PSNR +0.49、只比訓練約 **53 倍快**（整條流程含資料準備約 14 倍，資料準備重新計時中）、渲染 3.1 倍、顆數 0.44 倍、訓練峰值 2.66 GB（6 GB 筆電放得下）。
- **特定問題**（test 指標看不到，GT 量尺與 viewer 看得到）：路面在正確高度（b1／b4 地下層 A＋dist4 7.3／7.1 層 → 1.4／1.3 層，CityGS 1.6／1.8）、海面浮塊與水面下針狀面元幾乎沒有（b1 海面上方不透明面積 CityGS 477k m² vs 我方約 0.2k）、路燈與車回來、高樓立面覆蓋 88～96%（CityGS 75～94%；b2 GT 量尺）。
- **平均 1.5M 版三項都贏 CityGS**：PSNR +0.68、SSIM +.005、LPIPS −.012，顆數 0.65 倍、訓練約 47 倍快、峰值 3.9 GB；比 1M 版多 21% 時間換 +0.19 dB、LPIPS −.017（逐塊 16 塊全升 +0.12～+0.26）。
- **弱點**：1M 版 SSIM／LPIPS 比 CityGS 差 .004／.006（加速組合的代價，§9.3；1.5M 補回）；塔頂朝向與凹槽受訓練量限制（§9.4）；60k 長訓練的海面直條紋（§12）。

## 1. 流程總覽
```
MatrixCity 影像 5,621 張 ＋ GT 姿態（＝CityGS 的輸入）
  │ 資料準備（一次；scripts/prep_pipeline.sh，§2）
  ├─ COLMAP（GT 姿態）=> SfM 點 ─────────────────────────────┐
  ├─ Depth Anything V2 => 單目逆深度 ─ 每張 SfM 縮放 ──────────┤
  │                                                             ▼
  ├─ SfM 三角形校正深度＋可靠度分級（§2.3）──┬─> 塊外遮罩 A／B／C（§2.5）
  │                                          ├─> 平面深度 => 海面物件（共識平面＋海面格）（§2.6）
  │                                          └─> 稠密起點（＋海面鋪磚）（§2.7）
  └─ 4x4 分區、每塊顆數 ∝ 塊內可靠 SfM 點數（§2.8）
        ▼
  每塊 17k 步（§3～§6；16 塊依序或分卡平行，彼此獨立）
  ┌──────────────────────────────────────────────────────────────────────┐
  │ forward（lean：順便累加 V/C、|g|；前 75% 步數低解析度）                 │
  │ loss = L1＋2·L2＋SSIM（A=GT、B=隨機背景、C=0）                          │
  │      ＋每 8 步：dist、法向一致、逐貢獻深度上限（半解析度）              │
  │      ＋每 16 步：鄰域平面；每步：二元熵、尺度（只算畫面內）             │
  │ backward（盒外跳過、配對位元、飽和跳過、先加總）→ FusedAdam            │
  │ 每 150 步（≤ 70%）：MCMC 搬死顆粒＋增生到 cap（|g| 加權、面內） │
  │ 每 500 步（≤ 70%）：剪 V/C 最低 10%；每 1500 步（≤ 90%）：合併         │
  │ 海面層每步還原；浮塊收回                                                │
  └──────────────────────────────────────────────────────────────────────┘
        ▼
  16 塊各留盒內顆粒 => 合併 => 半精度部署 => 741 幀評測／viewer
```

**2.3 SfM 三角形校正深度**（`tools/make_tri_depths.py`）：每張影像用它自己觀測到的可靠 SfM 點做 Delaunay 三角形，
```
inv(p) = (s·d(p) + o) + interp_tri( 1/z_SfM − (s·d + o) )(p)        三角形內線性內插殘差；凸包外用最近點
可靠度 = 斜率級 + 8·大小級     斜率 = |grad log z|·fx（無因次）：級 0..4 = <1 / <3 / <8 / ≥8 / 凸包外；大小 = 三角形最長邊 <16/<64/<256/≥256 px
訓練只用 斜率級 ≤ 1 且 大小級 ≤ 3 的像素
```
- 平面的逆深度在影像座標上是仿射的 => 三角形內線性內插對平面精確，又保留三角形內單目的起伏。
- **深度誤差中位 2.15% → 0.15%**、「判在前方」15.7% → 2.2%；塔頂 18% → 0.45%（350 張對 MatrixCity 真深度；真深度只診斷，不進流程）。

## 3. 表示、分塊、渲染
### 3.1 表示 ⬜ 2DGS
```
面元 i：中心 mu_i、面內尺度 (s1, s2)、旋轉 q_i（t1, t2, n＝法向）、opacity o_i = sigmoid(raw)、SH 3 階顏色（16x3）
G_i(p) = exp(−(u² + v²)/2)，(u, v) = 射線與面元平面交點的局部座標
alpha_i(p) = o_i·G_i(p)      T_i(p) = prod_{j<i} (1 − alpha_j)      C(p) = sum_i T_i alpha_i c_i(view) + T_end·bg
```
每顆 59 個 float＝232 B（SH 高階佔 78%）；ckpt 另有 Adam 的 m／v。

### 3.2 塊外遮罩（`trimask`）🟨＋🟩
每塊每張影像一張三值圖，用**校正深度**把像素反投影成 3D 點 X(p)：
```
A 塊內           X(p) 在本塊盒內（外擴 m_in）                                   照常算光度 loss
B 塊外且空       X(p) 在盒外，且射線之後不再進入盒（外擴 m_c > m_in）             目標＝本步隨機背景色 => 本塊在這裡必須透明
C 不計分         第一表面在塊外但射線之後會進入本塊（被鄰塊高樓擋住）、無效深度、交界帶   權重 0
```
- 承 Mega-NeRF／HUG 等「每塊只用自己的像素」；**B 要求透明、C 的三分類**未查到前例。
- 改用校正深度（原本單目）：接縫旁 200 m 以上的監督 87% → 97%（單目把塔頂壓扁），b2 +0.058、b6 +0.019。

## 4. 損失
```
L = 0.8·L1 + 0.2·(1 − SSIM) + 2·L2                       像素目標：A=GT、B=本步隨機背景、C=渲染值（梯度 0）
  + 8·[ 100·L_dist + 0.0125·L_normal + 0.5·L_cap ]           每 8 步一次（權重乘 8），這一步用 0.5 倍解析度
  + 16·0.01·L_surf                                           每 16 步一次
  + L_H + 0.007·mean|s|                                      每步；opacity L1 = 0
  正則（熵、尺度）只對本步畫面內的顆粒取加權平均（regvis）
```
| 項 | 公式 | 作用 | 出處 |
|---|---|---|---|
| L1＋L2 | L1 外再加 2·L2 | L1 每像素只投 ±1 票，少數視角的強證據（塔頂）被稀釋；留住超高塔頂、收斂快（11-10 增生期逐項計時省約 8%；採用那批 2.5M 約 −2%） | 🟨 |
| L_dist | `sum_i sum_j w_i w_j |z_i − z_j|`，w = T·alpha | 同一條光線的貢獻集中到一層 | ⬜ 2DGS；每 8 步 🟩 |
| L_normal | 渲染法向對深度法向 `1 − n_render·n_depth` | 牆面朝向 0.77 → 0.94 | ⬜ 2DGS；每 8 步 🟩 |
| L_cap 逐貢獻深度上限 | `icap(p) = 1/((1 + 0.01) z_prior(p))`；`B(p) = sum_i T_i alpha_i max(z_i·icap(p) − 1, 0)`；平均到有先驗的像素 | 每一份落在先驗表面後面 > 1% 的混合貢獻依權重罰 => 地下層 | 🟩 |
| └ 只罰躺平 | 只在 \|n_z\| > 0.8 的先驗表面設上限 | 不誤罰立面與樓頂突出物 | 🟩 |
| └ 只補前面 | 梯度只推「落在後面的那一份」往前（光柵器 `depth_cap_grad_mode 3`） | 地下 −21～−43% | 🟩 |
| └ 海面上限 | 海面寬遮罩上，z_prior 換成海面共識平面深度 | 海面不被抬起 | 🟩 |
| L_surf 鄰域平面 | 每 400 步用 Morton 近鄰算 opacity 加權 PCA 平面（只對平坦且有足夠鄰居的）：`min(d_plane / s_inplane, 2) + 1.0·(1 − |n_i·n_plane|)`；權重 1k→10k 從 0 升到定值 | 不渲染的平面平滑；對新基準畫質平、立面 +6～8 pt，拿掉它地下 +25～36%（2.5M 每 4 步那批：朝向 0.91、浮塊 −22%） | 🟨 PCAsplat（2610.11011，同期）同樣 KNN PCA＋`1−|<v1,n>|`；我方 opacity 加權、只用平坦鄰域、截斷距離、週期計算 |
| L_H 二元熵 | `H(o) = −o ln o − (1−o) ln(1−o)`；1k～5,666 步只對 o < 0.5（往 0 推）、0.002；之後全部（雙向）、0.008 | opacity 兩極化，配 V/C 剪枝 | 🟨 SuGaR §5.1 |
| regvis | 熵／尺度正則只對 visibility_filter 內的顆粒取平均 | 少被看到的顆粒（塔頂）正則不再相對強 N/k 倍；b2 +0.045 | 🟩 |

## 5. 優化與排程
- FusedAdam；位置學習率 6.4e-5 → 6.4e-7（指數）；SH 3 階、高階每 16 步更新。
- **17k 步**；增生到 70%（11,900）；trim 與 MCMC 事件到 70%；合併 3k～90%（15,300）；之後只光度精修。
- **三段低解析度**：0～25% 用 0.35 倍、～50% 0.5 倍、～75% 0.75 倍、之後全解析度（🟨 coarse-to-fine 解析度排程，同 DashGaussian 方向）。
- **幾何步半解析度**：每 8 步的完整路徑步（dist、法向、上限）用 0.5 倍解析度（🟩）。
- train log 只記首尾；不跑訓練中驗證（評估一律離線）。

## 6. 起點與密度控制
### 6.1 起點 🟩
- 可靠 SfM 點＋**可靠像素沿校正深度反投影**，補到 0.9 cap（體素去重）；平面點另算名額；不撒空中隨機點；不去下方離群（`nodo`）。
- 有海的塊另外放海面鋪磚（§6.6）。裁到本塊盒（外擴 0.15 x 內側塊短邊）。
- 對 SfM 複製起點：四塊換塊打平、**F1 四塊都升**、塔立面 +2.4／+3.1 pt、朝向 +3～7 pt。

### 6.2 MCMC ⬜＋🟨
```
每 150 步（1k～70%）：
  死亡   o_i ≤ 0.005
  搬家   每個死顆粒抽活顆粒 j 當母點，機率 ∝ o_j·(1 + 2·|g_j| / mean|g|)        |g| 導引：🟨 AbsGS
         新點複製母點，兩者平分 opacity、縮尺度讓畫面不變（3DGS-MCMC Eq. 9）
  增生   N ← min(cap, 1.05 N)，同樣抽樣
  雜訊   每步 dmu = lr·5e5·sigmoid(100(0.005 − o))·Sigma·eps，Sigma = R diag(s1², s2², 0) Rᵀ  => 只推幾乎透明的、只在面元平面內
```
| 附加 | 做法 | 結果 | 出處 |
|---|---|---|---|
| ~~深度支撐閘門~~（11-20 拿掉） | 顆粒中心投到各視角，對校正深度的殘差多數票「在前方」=> 不准當母點 | 早期海上浮塊 −83～94%；現行配方上拿掉它分數、幾何、海面、時間都在雜訊內（被海面機制取代）=> 11-20 從配方拿掉（`+nogate`） | 🟩 |
| 面內增生 | 新點在母點平面內錯開 1 x 長軸；出生 1000 步內只准面內移動 | 低角度透空最少 | 🟩 |
| 補洞 | 每個增生事件最多 0.2% 顆放在洞／看穿處的先驗深度上 | 打平（保留） | 🟩 |
| 點精靈下限 `px_floor` | 每 1000 步重算像素長度，尺度不低於約 1 px | 燈柱回來、地面覆蓋 0.55 → 0.77、F1 +.017／+.034 | 🟩 |
| 增生後刪死顆粒 | 每 500 步刪 o ≤ 0.005 | 打平、少顆數 | 🟩 |

### 6.3 累加式 V/C trim 🟨
```
每個 lean forward 順便累加：V_i += sum_p T_i alpha_i（實際混合量）    C_i += 覆蓋像素數
每 500 步（≤ 70%）：score_i = V_i / C_i，剪掉最低 10%（沒被看到的這輪不剪）；累加器歸零
```
- **前例：TrimGS（arXiv 2406.07499）Eq. 5 已經把每個視角的貢獻除以投影像素數**（再取前 5 個視角平均、每 1000 步剪 10%）。我方的差別：跨**所有**視角「總和 ÷ 總和」、在訓練 forward 中累加（不另掃相機）、背包對偶解讀 `V − lambda·C > 0 <=> V/C > lambda`。同 N 渲染成本 −1/3、品質平。
- 累加（不另掃相機）：同品質、比週期 trim 快 19～33%。

### 6.4 合併後刪除 🟨
- 互為最佳、同平面、同色（色差 < 0.1）的鄰居做質量守恆的矩匹配合併，被併的刪掉並扣名額；3k～90%，每 1500 步、每次最多 2%。顆數 −24／−21%、海上浮塊 −50／−35%、PSNR 平、時間 −2～4%（b3／b12，全程版；`進展_1030至今.md` §3.5）。
- 承 surfel fusion（ElasticFusion 類判準）、NanoGS 的兩兩矩匹配；我方用在 2DGS 面元、訓練中做、扣名額。

### 6.5 顆數
- 每塊 cap ∝ 塊內可靠 SfM 點數（**預設平均 1.5M**，11-19 起；1M 版最終顆數 0.52M～1.28M）；均勻 cap 27.805、探針分配 27.828、SfM 分配 27.822（零成本）。

### 6.6 海面物件 🟩
**建物件**（`tools/make_sea_object.py`，資料準備時）：
1. 每張影像的海面區（校正深度無效或在凸包外、顏色均勻的連通區）用外圈可靠像素擬合平面（`make_plane_depth.py`）。
2. 各影像海面平面轉世界座標，加權中位＋去離群 => 共識平面；**水體自動偵測**（分開的水面各自一個高度；MatrixCity 一個水體，−2.565 m、30.8k 個 SfM 水面點）。
3. 海面格投票：可靠深度在平面上 => 棄權、在平面後面 => 反對、像海（顏色／深度）=> 贊成；交界補齊（像海 ≥ 2 x 前面有東西、不像海 ≤ 0.2 x 像海時補）；**只在有證據的地方鋪、不外推**。
**訓練中**：
- 錨定海面層：每格一顆鋪磚，每步位置還原、法向固定為平面法向、尺度夾在 0.5～2 倍格距；不搬家、不剪、不當母點、名額另算（延伸 SfM 錨點）。
- 海面上限：L_cap 在海面寬遮罩上用共識平面深度（§4）。
- 浮塊收回：海面格上方 > 1 格、或水面下 > 0.5 格，且離「非水面」可靠 SfM > 1 格的自由顆粒（水面上的 SfM 點就是水面本身，不當保護）=> 增生期交給 MCMC 搬家、之後每 500 步刪。
- 結果：b1 海面上方 > 20 m 浮塊 1,497 → 3、可見面積 −99%；水面下針狀面元 −99%（b1）／−97%（b3）；換塊 ±0.01。

## 12. 已知限制與開放問題
- **塔頂朝向**（b2 350 m 以上 50% vs CityGS 68%）與**凹槽**：訓練量限制（§9.4）；步數管朝向但 +60% 時間。
- **60k 長訓練的海面直條紋**：貼在水面 1 格內（不是浮塊），水面層在長訓練下擬合反光；17k 沒有。
- **SSIM／LPIPS**：1M 版落後 CityGS；平均 1.5M 版三項都贏（§0）=> 1.5M 要不要當預設待使用者決定（+21% 時間）。
- 玻璃塔（b3）是擬合失敗，CityGS 在它的訓練視角也只有 13～18.5 dB。
- 預讀在記憶體滿時只讀一次的頁面會被擠掉 => 已改讀兩次，待驗證。
