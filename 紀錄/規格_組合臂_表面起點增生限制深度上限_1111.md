## 2. 要新做的：只擋後面的增生限制（用校正深度）
**概念**：一顆顆粒如果在多數「看得到它那個位置、而且深度可靠」的訓練視角裡，都落在校正深度的表面**後面一點點**，它就是地下層的候選
=> MCMC 抽母點時幾乎不抽它（新顆粒不長在它那裡）。在表面**前面**的（路燈、車、陽台）一律不管。

**做在哪**：`internal/metrics/geom_gate.py` 的 `DepthSupport`（現有的深度支撐閘門，已經每 8 步把顆粒中心投到當前相機、對深度圖算相對殘差 r、逐顆投票）。
現在它判「一直在前方」（r < −δ）與「從未貼面」。加第三種票：
- **behind 票**：`margin < r < r_max`（r＝(顆粒深度 − 表面深度)／表面深度；深度圖值 <= 0 的像素不算觀測——可靠度過濾已經把不可靠的設成 0）。
- **為什麼要有 r_max**：r 很大＝這顆在該視角是被別棟樓擋住（它前面的表面是別的東西），不是地下層。11-08 視線一致性 v4 就是把「從大樓背面看過去」當證據才餓死牆面
  （`紀錄/實驗分析/33` §6）。地下層約在 1.5～3%，隔一棟樓是 5% 以上 => 只收窄帶。margin、r_max 都是相對深度（無因次），不是場景單位。
- 視窗結束時：有效觀測 >= 3 且 behind 票過半 => `behind[i] = True`。
- 新設定（預設全關，關的時候行為要與現在逐位元相同）：metric `depth_support_behind: bool = False`、`depth_support_behind_margin: float = 0.01`、`depth_support_behind_max: float = 0.05`。
- **作用**：只影響 MCMC 抽母點（density `geom_gate_sampling` 那條路：被判 behind 的顆粒抽樣機率乘很小的係數，與現有「無支撐」同一個係數）。
  **不要**讓它關掉二元熵、**不要**刪或搬顆粒（11-10～11 兩版「搬走」都掉畫質，`31` §4.7）。SfM 豁免不套用在 behind 票上（地下顆粒多半就在 SfM 點附近）。
- 可觀測性（必做）：首次判定與每 2000 步印一行——有效觀測比例、behind 比例、其中不透明的比例。拿不到深度時印一次 ⚠⚠。
- 調參腳本：`task_tune25.sh` 加元件 `tribh`（＝`tri`＋上面三個旗標，`depth_support_behind true`）。乾跑確認旗標有進訓練指令。
- 測試：`tests/` 加單元測試——(a) 預設關時 support 與現在相同；(b) 一顆在表面後 2% 的被判 behind、後 20% 的不判、前面的不判；(c) 深度 0 的像素不算觀測；(d) 顆數增減時狀態正確。
