## 2. 配方瘦身：逐項拿掉（b1、b4；30k；對底）
**為什麼**：底疊了十幾個機制，其中幾個當初是為了壓地下層／海面浮塊加的；深度上限現在直接處理地下層，它們可能已經多餘。11-09 同樣的拆解找出了位置 lr ×2 這個主因。
- 每臂＝底只關一項（`task_tune25.sh` 加元件 `no<項>`，一個元件只蓋那一項的旗標；乾跑確認）：
  | 元件 | 關掉什麼 | 旗標（關的值） |
  |---|---|---|
  | `nogate` | 深度支撐閘門＋增生取樣 | `metric.depth_support false`、`density.geom_gate_sampling false` |
  | `nohf` | 補洞放點 | `density.hole_fill_frac 0` |
  | `noip` | 增生方向限面內 | `density.inplane_offset 0`、`inplane_hold 0` |
  | `nonm` | 法向一致性 | `metric.lambda_normal 0` |
  | `nonp` | 鄰域平面約束 | 不帶 `np16` |
  | `nomg` | 合併後刪除 | `density.merge_prune false`（或 `merge_interval 0`，看程式怎麼關） |
  | `nol2` | L1 混 L2 | `metric.rgb_l2_weight 0` |
  | `nopx` | 點精靈下限 | `density.px_floor 0` |
  | `nohp` | 刪死顆粒 | `density.harvest_prune_dead false` |
  | `mge1` | 合併改成「只併渲染誤差 < 0.1 的、不設額度、不透明質量守恆」 | `density.merge_render_eps 0.1`、`merge_opacity mass`、`merge_max_frac 1.0`（旗標名以程式為準；11-08 的 `PF2DMMR_` 那一臂） |
- [solo]（時間要可比）。評估：`task_tune25.sh eval <塊> loo <各臂>`，基準＝底，`TUNE_EXTRA` 帶鄰域平面 30k 與 A＋dist4。
- **判讀**（每一項給一個結論）：
  - 關掉後畫質、F1、地下、貼地、立面、海面、路燈／車都在雜訊內（換塊 ±0.03 dB、F1 0.003）=> **可刪**（時間有省更好，沒省也刪——配方變簡單）。
  - 關掉後某一欄明顯變差 => 留，註明它在保什麼。
  - 關掉後變好 => 特別標出，回報使用者。
  - `mge1`：對底的 F1／貼地覆蓋／顆數／時間；兩塊都不傷且幾何變好 => 提給使用者換預設。
- 兩塊結論一致的才動；不一致的列出來不動。**不要自己改預設或改底**，把表貼回來由使用者決定。

## 3. 加速組合（看過 §1 的表再排；b1、b4；[solo]）
元件（都疊在底上；每個都要乾跑確認旗標）：
| 元件 | 做什麼 | 預期 | 備註 |
|---|---|---|---|
| `s20g70` | 全長 20k、增生期 70% | −31% | 已有；舊底上 F1 −.005～.008、地下 +0.2～0.4 層——新底有深度上限，地下可能不回來 |
| `lowres` | 前 1/4 用 1/2 解析度、到 1/2 用 3/4；低解析度步不算 dist | −12～15% | 已有；確認低解析度步的深度上限圖、上限遮罩（`cmflat`）、校正深度都有跟著縮（`_downscale_batch` 的註解寫了哪些使用端會按比例取樣；上限圖是新的，要驗） |
| `log0` | `train_log_interval 0`＋其他不在 GPU 上的空轉（依 §1 的「迴圈外」那一列決定清什麼：影像預先放 GPU、關掉每步的進度列／hook 等） | §1 量到多少算多少 | **必須無損**：同種子下 loss 曲線與 30k 的換塊分數在重跑雜訊內 |
| `geo8` | 幾何類 loss 對齊到同一步：dist 每 4 步 → 每 8 步（權重 ×2，期望值不變），與法向、深度上限同一步 | −3～5% | dist 每 4 步當初是從每 1 步調來的（−12%、品質平）；每 8 步沒測過 |
- 臂：`s20g70`、`lowres`、`log0`、`geo8` 各自單開（知道各自的效果）→ `s20g70+lowres`、`s20g70+log0+geo8`、`s20g70+lowres+log0+geo8`（全開）。
  §2 判成「可刪」的項目，在全開臂之外再加一臂「全開＋瘦身」。
- 評估同 §2（標籤 `speed`）。**過關**：對底 換塊 ΔPSNR、LPIPS 在雜訊內；F1 掉不超過 0.01；地下覆蓋、貼地覆蓋、立面、路燈／車不變差；時間照實報。
  每臂都要回報**兩個時間**：純訓練（tfevents 首尾）與整個任務牆鐘（含啟動準備與收尾的 chart_data；11-09 量到收尾每塊約 156 秒、準備 24～44 秒——
  純訓練降到 5 分時這兩段會變成大頭，一起列出來，但先不要動它們）。
- b1、b4 都過的最快一臂補 b3；不自排全場景。
