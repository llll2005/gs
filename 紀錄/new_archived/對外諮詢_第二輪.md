# 對外諮詢（第二輪）：一個在**訓練資料上**的擬合失敗

> 2026-09-03。第一輪的四個假說我已用實測分掉了（見 §3），所以這一輪只問一件事。
> **請先讀 §2 的排除清單再回答**，重複已排除的方向對我沒有幫助。

## 1. 現象（一句話）

**2D Gaussian Splatting，在它自己的訓練影像上**，把 ~60% 的高紋理區域重建到
**94% 的紋理能量**，另外 **~40% 只重建出 16%**，而**兩邊的亮度（DC）都正確**。
失敗區的位置**跨配方高度固定**。

### 量測定義
- 影像切成 48×48 px tile，逐 tile 對 GT 線性迴歸 render，取相關係數 `corr`
- 只計 **GT 對比最高的 15%** 的 tile（排除平坦區，避免 `corr` 在低變異下失去意義）
- 「失敗」= `corr ≤ 0.6`

```
                GT 紋理   render 紋理   render/GT   GT 亮度   render 亮度
成功 (60%)      0.1612     0.1508       0.94        0.333     0.324
失敗 (40%)      0.0789     0.0129     **0.16**      0.310     0.294
```
**是雙峰，不是連續退化。**

### 設定
| | |
|---|---|
| 表徵 | 2DGS surfel，SH degree 3 |
| 密度控制 | 3DGS-MCMC（relocation 式，非梯度門檻 ADC）|
| 規模 | **2.34M 個 primitive / 284 張訓練影像**（≈ 8,200 個/張）|
| 硬體 | 單張 6 GB，60,000 步，約 10 小時 |
| **評測** | **`val ⊂ train`** —— 那 36 張評測影像**在訓練集內** |

**⇒ 這是「擬合失敗」，不是泛化落差。模型訓練時看過那些影像。**

## 2. ⛔ 已用實測排除的（請勿重複建議）

### 2.1 不是資料或評測的 bug（五項獨立檢查）
| 嫌疑 | 驗法 | 結果 |
|---|---|---|
| GT 配對錯位 | test 圖 GT 半 vs 原始影像逐張相關 | **corr 0.9997**（本專案 8 月確實發生過一次 off-by-one，已修）|
| GT/render 左右顛倒 | 與原圖相關 + 梯度能量 | 順序正確 |
| 相機內參讀錯 | 讀碼 | PINHOLE 走對分支；**無畸變參數被忽略** |
| val 其實是 held-out | 讀碼 | `split_mode=reconstruction` ⇒ **val ⊂ train 確認** |
| **render 只是位移** | 逐 tile 在 ±8px 搜尋最佳位移 | 成功 tile 提升 **0.000**；失敗 tile 提升僅 **+0.031**（0.339→0.404）⇒ **不是對不齊，內容真的沒重建** |

### 2.2 不是「輸入資訊不足」（SfM 點雲投影，逐 tile）
```
              深度      SfM 點數    深度離散度   觀測視差角
失敗 / 成功   1.09x    **1.43x**    0.83x        1.08x
```
⇒ 深度相同（**不是遠場**）、SfM 點**反而更多**、零點 tile **0.0%**、
幾何**更平坦**（不是深度不連續）、**觀測角度多樣性相同**（不是多視角覆蓋不足）。

### 2.3 不是我方高斯的空間統計（投影 2.34M 高斯，逐 tile）
```
              高斯/像素   投影半徑px   opacity
失敗 / 成功     0.62        1.18        1.27
```
⇒ 三個方向都「對」，但**幅度遠不足以解釋 6 倍的紋理落差**。
獨立反證：顆數 +15%（2.34M→2.70M）在同一批 tile 上只把 `corr` 從 0.287 推到 0.327。

### 2.4 不是密度控制／族群組成（**十次**介入，全部碰不到）
```

absgrad w=1→2→3          46.17 / 46.08 / 46.03
收割期移除 opacity L1     46.04（判死率 15.03%→7.82%、確信率 +15.59pp）
收割期回收死粒子          45.99（判死率 15.03%→**0.00%**）
關閉週期 trim             46.55（**略差**）
```

**⇒ opacity 分布可以被整個重塑（死亡率 15%→0%、確信率 23%→39%）、trim 可以整個關掉，
而失敗率一動也不動。**

## 3. 第一輪四個假說的實測結果（供參考，避免重走）
