## 0. 為什麼
- 海面沒有 SfM、校正深度無效 => 那裡的顆粒只受光度約束。四輪下來的共同形狀：清掉一層，另一層接手畫
  （上方浮塊 −40～−92% 之後，露出 2.5 km 深、0.9～1.5 km 大的面元；海面本身變成巨大面元疊成的霧）。
- 平面 v1 已經證明兩件事：影像定義的海面區幾乎全是海（誤罰約 0%）、外圈擬合的平面誤差中位 0.6～1.8%。
  缺的是**結構**：平面上有一層保證鋪滿、動不了、不會長大的顆粒，其他顆粒才有條件退場。
- 判準（使用者 11-15）：viewer 裡海面浮塊與海底的東西**完全不見**才算有用；部分減少＋多花時間＝沒用。

## 1. 前提檢查（CPU；全部先做，把表貼回來再實作 §2 之後的東西）
用 b1、b3、b12（有海的三塊）。GT 深度只用來量。
| 編號 | 量什麼 | 過關 |
|---|---|---|
| P1 | 每張影像每個海面區擬合出的平面（法向、截距，轉到世界座標）彼此多一致：法向夾角、在區重心處的相對深度差的分布 | 中位 < 單張自己的殘差（self_tol 那個量）=> 可以合成一個平面；有兩群以上（不同高度的水面）=> 分群各自一個平面 |
| P2 | 共識平面對 GT：海面像素上的相對深度誤差（中位、p90），和單張平面比 | 中位比單張小；p90 < 2% |
| P3 | §2 的海面格反投影回每張影像的涵蓋：GT 海面像素被蓋到的比例（v1 單張區只有 42～56%）；蓋到的像素裡不是海的比例，分「前面有擋的東西」與「真的不是海」 | 涵蓋明顯高於單張區；「真的不是海」< 1% |
| P4 | 海面格的數量、鋪磚要幾顆（§3 的間距）佔該塊 cap 的比例 | 報數字；> 10% 要先回報 |
| P5 | 現成模型（新底 6、組合 v1）：中心落在海面格上方／下方、不在平面上（離平面 > 3 x 自己的像素長度）的顆粒數、Σ 不透明度 x 面積、它們在海面像素的出力（V/C 的 V） | 只報數字——這是 §4、§5 要清掉的量，也是訓練後的對照 |
- P1 需要 `tools/make_plane_depth.py` 多輸出每個區的平面參數（相機座標的 n、c 與區的像素數、殘差）；現在只存外推深度圖。

## 2. 3D 海面物件（離線工具，新檔 `tools/make_sea_object.py`）
- 輸入：`make_plane_depth.py` 每張影像的海面區（kind 2）與平面參數、相機、校正深度與可靠度。
- **共識平面**：所有區的世界平面，依區像素數加權的穩健估計（先中位、丟掉離群的區再重擬；用各區外圈的可靠像素反投影點直接合起來擬合也可以，兩者擇一並在 P2 比）。
  P1 出現兩群以上時分群，每群一個平面、一份海面格。
- **海面格**：平面上的規則格子，邊長＝§3 的鋪磚間距。每一格的格心投到每張訓練影像：
  - 贊成票：落在該張的海面區內。
  - 反對票：該像素的校正深度可靠，而且表面在平面上或平面後面（深度 >= 平面深度 x (1 − margin)）=> 那裡看到的是有 SfM 的陸地或穿過平面看到更低的東西。
  - 棄權：該像素可靠深度在平面前面（被擋住）、在影像外、或兩者都不是。
  - 海面格＝贊成 >= 3 張 而且 贊成 > 反對（相機數比例，沒有場景單位）。
- 輸出 `<dataset>/sea_object/block_<b>.npz`：平面（n、c）、格子原點與兩個面內軸、邊長、海面格的索引、每格的贊成／反對票數。
  另存每張影像的「海面格反投影遮罩」（uint8 PNG，解析度同校正深度；有擋的像素＝該像素可靠深度在平面前面 => 不標）。
- 範圍照稠密起點現有的裁切規則（塊盒＋它原本的外擴），不另外發明。
- 可觀測性：每塊印平面法向與世界 z 軸的夾角、海面格數、票數分布、反投影遮罩佔畫面的比例。

## 3. 錨定的海面層
**起點**（`tools/make_tri_dense_init.py`）
- 新選項 `--sea_object <dir>`：平面點裡的海面部分不再用反投影體素，改成**海面格的格心各一顆**（顏色＝贊成票影像在該像素的顏色中位）。
  立面的平面點、陸地照 v2（`--plane_sep`、`--drop_outliers`）不動。
- 鋪磚間距：讓「最近可見訓練相機裡一格約 P 像素」，P 預設 16（像素單位；用所有海面格的最近可見深度中位換算成一個全塊共用的邊長，報出來）。P4 用同一個數。
- 另存一份標記 `block_<b>_sea.npy`（起點 PLY 裡哪些列是海面層）；PLY 格式不變。
- 海面層有自己的名額，不佔 SfM 分配的 cap（同 v2 的作法）；顆數另外報。

**訓練**（`internal/density_controllers/mcmc_2dgs_density_controller.py`；設定 `sea_layer_dir`、`sea_layer_scale_max`）
- 逐顆狀態 `_sea`（跟著 N 走，同 `_anchor`／`_pxf_log` 的維護方式）。開訓時由標記檔設定。
- 每步結束（跟 `_sfm_restore` 同一個 hook 的時機）：
  - **位置**還原到格心（沿用錨點的還原；MCMC 雜訊、光度梯度都動不了）。
  - **朝向**：法向軸固定為平面法向（面內轉角照學）。
  - **大小**：兩個尺度都夾在 [0.5, `sea_layer_scale_max`] x 鋪磚邊長（預設上限 2；下限保證相鄰磚有重疊、不留縫）。點精靈下限照常，但不會比這個下限小。
  - 不透明度、顏色（含 SH）照學。
- 不參與：relocation、補洞、V/C trim、合併、刪死顆粒（同錨點的豁免清單）。不當增生母點（鋪磚已經是滿的，不需要子代）。
- 可觀測性（每 2000 步）：海面層顆數、不透明度中位與 < 0.5 的比例、尺度碰到上／下限的比例、每步被還原的位移中位。
  首次觸發印 ✅；標記檔找不到或對不上列數印 ⚠⚠ 並中止（不要靜默當成沒有海面層）。
- 測試：關閉時逐位元相同；海面層顆粒訓練 200 步後位置與格心差 < 1e-6、法向與平面法向夾角 < 0.1°、尺度在界內；relocation／trim／合併事件前後 `_sea` 的顆數不變。

## 4. 海面像素上的約束（三項，各自一個元件；前兩項不改光柵器）
先分清兩種像素遮罩：
- **寬遮罩**＝§2 的海面格反投影遮罩（涵蓋大；可能包含「前面站著沒有可靠深度的東西」的像素，例如岸邊的玻璃樓）。只用在「罰平面後面」——擋在前面的東西不受影響。
- **窄遮罩**＝該張影像自己的海面區（kind 2；顏色均勻、量過誤罰約 0%）。「罰平面前面」只能用這個。

| 元件 | 做什麼 | 改哪裡 |
|---|---|---|
| `seaback` | 寬遮罩的像素補上深度上限（平面深度 x (1+margin)）。就是現有 `pcs` 的做法，只是遮罩與深度換成 3D 海面物件的（涵蓋較大、平面較準） | metric：`depth_cap_plane_dir` 指到新的目錄即可 |
| `seafront` | 窄遮罩的像素：渲染的**期望深度**比平面深度淺超過 f 就罰，`relu(1／(1+f) − z_期望／z_平面)`，f 預設 0.02（相對深度）。和法向、上限同一步（每 8 步）。海面層被錨定在平面上，這個梯度只會把前面的東西往透明推 | metric：仿 `see_through_loss`，方向相反；設定 `sea_front_reg`、`sea_front_margin` |
| `seanop` | 中心落在海面格的正上方或正下方、不是海面層、離平面超過 3 x 自己像素長度的顆粒：不准當增生與 relocation 的母點（抽樣機率設 0）。不刪、不搬 | density controller：抽樣前把這些的機率清 0 |
| `seafull` | 寬遮罩的像素，上限的梯度用完整模式（給後面的貢獻也算），其他像素維持只補前面。做法：上限圖用**負號**標這些像素，backward 看到負的 icap 就用 \|icap\| 且走模式 0 | **光柵器 backward**（forward 取絕對值；渲染與通道不變）。要重編兩台 |
- `seanop` 的「像素長度」用 `px_floor` 的快取（最近可見訓練相機裡 1 像素的長度），沒有公尺常數。
- `seafull` 的檢查照 `tools/check_depth_cap.py` 的作法加一項：混合遮罩（一半像素負號）下，正號像素的梯度與全域模式 3 相同、負號像素的梯度與全域模式 0 相同；上限圖全正時與現在逐位元相同。
- 這四項都不刪顆粒。退場的路徑只有一條：被壓到透明 => 現有的刪死顆粒／relocation 回收。

## 6. 評估與過關
現成的海面欄（上方浮塊數、> 20 m 的、Σ 不透明度 x 面積、海面層覆蓋）＋P5 的三個量＋巨大面元數（3σ > 鋪磚邊長 x 8 的顆數，分海面格內外）＋
換塊 ΔPSNR／LPIPS、F1、陸地地下覆蓋、純訓練時間、總顆數（海面層另列）。
- **過關**（對 S0）：
  - 海面格上方與下方、不在平面上的可見量（Σ 不透明度 x 面積、在海面像素的出力）降到 S0 的 5% 以下；海面格內的巨大面元 0 顆。
  - 海面層覆蓋不降（海面像素的累積不透明度中位 >= S0）。
  - 換塊 ΔPSNR 在 ±0.03 dB 內、LPIPS 不變差；F1、陸地地下覆蓋不變差；純訓練時間 +3% 以內。
  - **使用者看 viewer**：海面上空、海底沒有東西，海面不是霧。數字過了才請使用者看。
- 沒過時要回報的拆因：殘留的是「海面格外的海」（共識範圍不夠大）、「窄遮罩沒蓋到的像素」（`seafront` 管不到）、還是「在遮罩內但梯度壓不掉」。

## 7. 已知風險與不做的
- 海面格以外的海（塊盒外、沒有 3 張影像贊成的遠海）這份規格管不到；殘留集中在那裡的話，下一步是放寬範圍，不是加刪除規則。
- 海面的反光／波紋靠海面層的 SH 與面內尺度表現；磚太大（P 太大）會糊、太小吃名額 => P4 與 S1 的海面像素 PSNR 一起看，需要時加一臂 P＝8。
- 岸線：海面格的反對票會把有可靠深度的岸邊排除；岸邊沒 SfM 的淺灘可能被當成海——P3 的「真的不是海」那一欄會看到。
- 不做：刪除海面範圍內的顆粒、往下沉、SfM 投票的任何新版（已關閉的線）；立面的錨定（等牆後真值刪除的結果，另寫）。
